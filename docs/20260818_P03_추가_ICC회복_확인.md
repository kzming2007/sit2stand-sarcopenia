# P03 추가와 ICC 회복 — 표본 구조 가설의 직접 검증

작성 2026-08-18 · 관련 `20260814_G2파이프라인_완성_및_표본크기검토.md` §5~6,

## 결론

**피험자 1명을 추가하자 각도 지표 ICC 가 전부 회복됐다. 편향과 LoA 는 거의 변하지 않았다.**

| 지표 | 2명 20 trial | **3명 25 trial** | 편향 (2명 → 3명) |
|---|---|---|---|
| `left_hip_range_mean` | **−0.011** | **0.691** | −16.28° → −15.60° |
| `right_hip_range_mean` | **−0.009** | **0.630** | −13.63° → −11.95° |
| `trunk_lean_max` | 0.200 | **0.822** | −6.91° → −5.51° |
| `trunk_lean_range_mean` | 0.069 | **0.656** | −7.96° → −6.85° |
| `left_knee_range_mean` | 0.122 | **0.566** | −15.07° → −15.58° |
| `right_knee_range_mean` | 0.486 | **0.750** | −0.84° → −1.33° |
| `time_stand2sit` | 0.848 | **0.910** | +0.11 → +0.07초 |
| `time` | 0.994 | 0.972 | −0.030 → −0.027초 |
| `alcazar_rel_power_Wkg` | 0.993 | **0.997** | +0.014 → +0.012 |

`left_hip` 의 ICC 가 −0.011 에서 0.691 로 갔는데 **편향은 −16.28° 에서 −15.60° 로,
LoA 폭은 32.8° 에서 31.2° 로 사실상 그대로다.**

**측정이 좋아진 것이 아니다.** 오차 크기는 변하지 않았고 ICC 의 분모에 있던
대상 간 분산이 채워진 것이다.

> `20260814` §5 에서 시뮬레이션으로 예측하고, `20260817` §5 에서 "ICC 가 낮은 이유는
> 측정이 아니라 표본 구조다"라고 진단한 것을 **피험자를 추가해 실측으로 확인했다.**
> ICC 가 측정 품질만의 함수가 아니라는 것을 자기 데이터로 보인 사례다.

## 1. 무엇이 달라졌나

| | P01 | P02 | **P03** |
|---|---|---|---|
| 성별·연령 | 남 20대 | 남 20대 | **여 58세** |
| 신장 | 173cm | 173cm | **154.1cm** |
| 체중 | 92kg | 63kg | 60.3kg |
| 의자 좌면 | 44cm | 44cm | **53cm** |
| Kinect 높이 | 82cm | 82cm | **93cm** |
| 5STS (폰) | 7.90 ± 0.36초 | 9.23 ± 0.42초 | **8.53 ± 0.06초**(T02~T05) |
| Alcazar 상대파워 | 4.76 W/kg | 4.07 W/kg | **2.46 W/kg** |

두 피험자의 신장이 173cm 로 같아 각도의 대상 간 분산이 구조적으로 없던 상태에서,
**154.1cm 가 들어오자 분산이 생겼다.**

### 값의 타당성

- **Alcazar 2.46 W/kg** — 문헌 참조치는 약 75세 여성 2.0±0.6 W/kg 이다.
  58세이므로 75세 참조치보다 높은 것이 정상이며 타당한 범위다
- **5STS 8.53초** — Bohannon 임상 참조치(건강 성인) 7.5±2.4초 범위 안이다

연령이 다른 피험자에게서 **연령에 맞는 값**이 나왔다는 점은 파이프라인 타당성의
추가 증거다.

## 2. 촬영 품질 — 밤 촬영도 문제없었다

```
폰     검출률 100% × 5 trial      Kinect  검출률 100% × 5 trial
QC     10/10 통과                 동기화  5/5 "동일 사건으로 판단"
시차   +0.10 ~ +1.20초            녹화    폰 21~23초 / Kinect 20초, 1.15GB
```

그 방의 **유리문 IR 역광**이 주간에 depth 를 21% 까지 떨어뜨렸던 위험원인데,
밤에는 그 위험이 없다. Kinect depth 는 적외선 ToF 라 가시광 밝기와 무관하다.

> 폰은 반대로 가시광이므로 실내등이 필요하다. 이번에는 충분해서 100% 가 나왔다.

### T01 은 4회다 — 두 장비가 독립적으로 확인

첫 시행에서 반복을 한 번 덜 수행했다.

| | 기립 검출 | 총 시간 |
|---|---|---|
| 폰 | **4회** | 7.67초 |
| Kinect | **4회** | 8.23초 |

평활 강도를 0.04~1.0 으로 바꿔도 기립이 3.4 / 5.2 / 7.0 / 8.9초에 1.8초 간격으로
**4개만** 나온다. 서로 다른 센서·알고리즘이 같은 답을 냈으므로 분할 오류가 아니다.

`--reps 4` 로 처리해 QC 를 통과시키고 G3 에 포함했다. **다만 AWGS 5STS ≥ 12초 판정에는
쓰지 않는다** — 그 기준은 5회 수행을 전제한다.

## 3. 한계 — 의자 높이가 피험자 간에 다르다

| | P01·P02 | P03 |
|---|---|---|
| 의자 좌면 | 44cm | **53cm** |
| Alcazar `d = 0.5×신장 − 의자높이` | 42.5cm | **24.1cm** |

표준 5STS 는 43~45cm 의자를 쓴다. 53cm 는 높은 편이고, 신장 154cm 에는 상대적으로
더 높다.

| 영향 범위 | 판단 |
|---|---|
| **G3 지표별 일치도** | **무관.** 두 장비가 같은 의자·같은 동작을 본다 |
| 대상 간 수행시간 비교 | 교락. 의자가 높으면 과제가 쉬워 빨라진다 |
| AWGS 12초 해석 | 기준이 표준 의자를 전제한다 |
| Alcazar 파워 절대값 | `d` 에 직접 들어간다. 대상 간 비교 제한 |

**본 연구의 주 질문(RQ1, 장비 간 일치도)에는 영향이 없으므로 재촬영하지 않는다.**
대신 피험자별 의자 높이를 기록에 남기고 위 제한을 명시한다.

이후 촬영은 **44cm 로 통일**한다.

## 4. 여전히 남는 제한

- **신뢰구간이 넓다.** `trunk_lean_max` 는 ICC 0.822 이지만 CI 가 [0.09, 0.95] 다.
  3명으로는 점추정만으로 판단할 수 없다. `20260814` §5 의 시뮬레이션대로 대상 3명의
  기대 CI 폭은 1.2 수준이다
- **65세 이상이 없다.** 20대 2명 + 58세 1명이다. 근감소증 주 대상인 고령층 일반화는
  여전히 불가능하다
- **편향은 그대로다.** ICC 가 올라간 것이 오차가 줄었다는 뜻이 아니다.
  각도 편향 −5.5 ~ −15.6° 는 유지된다. 보고할 때 두 값을 함께 제시한다

### 보고 방침

`20260814` §6 의 전환안을 유지한다. **Bland-Altman 편향·LoA 와 재현성을 주 결과**로
쓰고, ICC 는 표본 구조에 민감하다는 점을 이 문서의 대비표와 함께 제시한다.

**ICC 가 −0.011 에서 0.691 로 바뀌는 동안 편향이 그대로였다는 사실 자체**가
"상관·ICC 만으로 일치도를 판단하지 말라"는 주장의 가장 강한 근거다.
