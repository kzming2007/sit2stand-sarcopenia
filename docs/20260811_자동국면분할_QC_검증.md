# 자동 국면 분할·QC 검증

작성일: 2026-08-11
대상: Boswell et al. (2023) 공개 코드·궤적과 현재 `select_magnitude()` 구현

## 결론

현재 자동 magnitude 선택은 **5회 반복 수를 만족하는 후보를 찾는 QC를 부분 자동화**한다. 고정값 `magnitude=1.0`보다 반복 수 기준 통과율은 높아졌고, 저자 `realign`에 남은 일부 착석 경계에서도 평균 오차가 감소했다.

그러나 전체 사람 검수 경계가 공개되어 있지 않고, 비교 가능한 57개 경계 중 16개는 오히려 악화됐다. 자동 선택 실패 30명과 후보 구간이 여러 개인 17명도 있었다. 따라서 기존 문서의 `수동 개입 문제 해결`은 근거보다 강하다. 현 단계의 적절한 표현은 다음과 같다.

> 프로토콜 반복 수를 이용해 평활 강도 탐색과 QC를 자동화하는 후보를 구현했다. 공개 코드의 부분 수정 경계에서는 평균 오차가 감소했으나, 완전한 경계 정확도와 지표 보존은 확인되지 않았다.

## 1. 1차 출처 감사

근거는 [Boswell et al. (2023)](https://doi.org/10.1038/s41746-023-00775-1)과 [공식 GitHub](https://github.com/stanfordnmbl/sit2stand-analysis)의 로컬 commit `eb45993b1b9237a580dac8a4211a6473e722211f`만 사용했다.

| 구분 | 확인값 | 해석 |
|---|---:|---|
| 논문 제출 영상 | 493 | 논문 본문 모수 |
| OpenPose 처리 성공 | 489 | 논문 본문 모수 |
| 최종 분석 코호트 | 405 | 논문 본문 모수 |

| `dataMovement.csv` | 560명 | 공개 중간 산출표. 최종 405명과 다름 |
| 내려받은 `.npy` | 629개 | 공개 궤적 파일 수 |

| 기존 자동 처리 부분집합 | 250명 | 위 324명에서 코드 표시 대상을 제외한 분석용 부분집합 |

공식 코드의 사람별 처리 항목은 성격을 나눠야 한다.

| 코드 항목 | 대상 | 성격 |
|---|---:|---|
| `tofix` | 49명 | 시작·끝 crop 직접 지정 |
| `realign` | 41명, 착석 경계 59개 | 특정 `downs` 프레임 직접 교체 |
| `tofix ∪ realign` | 84명 | 두 목록의 중복 6명 |
| `tocheck` | 6명 | 검토 목록. 전부 수동 보정으로 간주할 수 없음 |
| `toremove` | 13명 | 제외 목록. 수동 보정과 구분해야 함 |
| `process_subject` 특수 분기 | 6명 | crop, magnitude, 프레임 제거, 코 좌표 보정 |
| 직접 처리 개입 고유 대상 | 89명 | `tofix ∪ realign ∪ 특수 분기` |

기존 `103/560 수동 보정`은 부정확하다. `103`은 `tofix`, `tocheck`, `toremove`, `realign`의 고유 ID 수이며 서로 다른 성격을 합친 값이다. 논문 본문도 103명을 수동 보정했다고 보고하지 않는다.

### 1.2 논문 서술과 코드

| 주장 | 사실확인 | 판정 |
|---|---|---|
| 6 Hz, 5차 zero-lag Butterworth | 논문은 zero-lag로 기술하지만 `utils.py`는 단방향 `lfilter` 사용 | 불일치 확인 |
| `_ang_acc`는 각가속도 | `utils.py`가 `acc` 대신 `vel` 평균 반환 | 구현 오류 확인 |
| `_range_mean`은 반복별 범위 평균 | 둘째 루프에서 `y`를 갱신하지 않아 마지막 구간 범위를 반복 추가 | 구현 오류 확인 |
| 자동 magnitude가 수동 문제 해결 | 반복 수 조건을 만족하는 magnitude를 고른 것만 확인 | 과장. 경계 정확도 별도 검증 필요 |

`_ang_acc`와 `_range_mean` 정정값은 논문 수치 재현용 값과 분리해야 한다. 이번 국면 검증은 논문 호환 정의와 단방향 필터를 사용해 경계 변화의 영향만 비교했다.

## 2. 검증 계약

### 비교 조건

- `author-coded`: 저자 crop·특수 magnitude·`realign`을 적용한 재현 경로
- `fixed`: 동일 전처리와 crop 후 `magnitude=1.0`, `realign` 미적용
- `auto`: 동일 전처리와 crop 후 현재 `select_magnitude()`, `realign` 미적용
- 자동 탐색 범위: `0.02~2.0`의 30개 기하간격 후보

### 지표

- 완화 반복 수 성공: `ups=5`, `downs=5 또는 6`
- 엄격 반복 수 성공: `ups=5`, `downs=6`
- 경계 오차: `realign`에 기록된 착석 경계까지의 절대 프레임·시간 오차
- 지표 보존: `dataMovement`의 수행 시간, STS/착석 시간, 몸통 최대각, 우측 무릎·엉덩이 범위 대비 MAE
- 모호 사례: 후보 없음, 후보 1개뿐, 분리된 후보 구간이 여러 개

`realign`은 수정된 일부 착석 프레임만 제공한다. 완전한 STS 시작·종료 정답이나 사람 검수 전체 경계가 아니다.

## 3. 실행 결과

### 3.1 재현 확인

`author-coded` 경로는 456명 모두 처리됐고 `dataMovement`의 주요 지표를 부동소수점 오차 수준으로 재현했다. 예를 들어 전체 수행 시간 MAE는 `1.53e-9초`, 몸통 최대각 MAE는 `2.47e-8도`였다. 따라서 아래 차이는 검증 스크립트의 재현 실패로 설명되지 않는다.

### 3.2 반복 수 기준

| 모수 | 조건 | fixed | auto |
|---|---|---:|---:|
| 공개 중간표·궤적 교집합 456명 | 완화 기준 | 400/456 (87.7%) | 426/456 (93.4%) |
| 공개 중간표·궤적 교집합 456명 | 엄격 기준 | 373/456 (81.8%) | 387/456 (84.9%) |
| 최종군 중 궤적 연결 324명 | 완화 기준 | 291/324 (89.8%) | 307/324 (94.8%) |
| 최종군 중 궤적 연결 324명 | 엄격 기준 | 283/324 (87.3%) | 291/324 (89.8%) |

456명에서 자동 선택은 fixed 실패 27명을 완화 기준으로 추가 통과시켰고, fixed 통과 1명은 자동 선택에서 후보를 찾지 못했다.

자동 선택 상태는 다음과 같다.

| 상태 | 456명 | 최종군 연결 324명 |
|---|---:|---:|
| 단일 연속 후보 구간 | 405 | 290 |
| 후보 없음 | 30 | 17 |
| 분리된 후보 구간 여러 개 | 17 | 15 |
| 후보 1개뿐 | 4 | 2 |

### 3.3 부분 경계 reference

| 항목 | fixed | auto |
|---|---:|---:|
| reference | 41명·59개 | 비교 가능 57개 |
| 평균 절대오차 | 21.95 frame, 0.685초 | 15.02 frame, 0.446초 |
| 중앙 절대오차 | 18 frame | 11 frame |
| 3 frame 이내 | 0/59 | 16/57 (28.1%) |

동일한 57개 경계에서 자동 선택은 29개 개선, 12개 동일, 16개 악화였다. 평균은 개선됐지만 대부분이 정밀하게 일치한 것은 아니다. 후보의 경계 개수나 순서가 달라지면 `realign`의 index 대응도 모호할 수 있다.

### 3.4 저자 지표 보존

| 지표 | fixed MAE | auto MAE |
|---|---:|---:|
| 전체 수행 시간 | 0.0046초 | 0.2527초 |
| 일어서기 누적 시간 | 0.0914초 | 0.5247초 |
| 앉기 누적 시간 | 0.0872초 | 0.5069초 |
| 몸통 최대각 | 0.0215도 | 0.2699도 |
| 우측 무릎 범위 평균 | 0.0584도 | 1.0877도 |
| 우측 엉덩이 범위 평균 | 0.0341도 | 0.6202도 |

자동 선택은 반복 수를 맞추기 위해 기존 경계를 이동시키므로 저자 최종 산출표와의 오차는 커졌다. `dataMovement`는 저자 개입을 포함한 내부 기준이며 외부 motion-capture ground truth가 아니다. 이 결과만으로 어느 경계가 임상적으로 더 정확하다고 판단할 수 없다.

## 4. 현재 주장 범위

### 확인됨

- 고정 magnitude보다 프로토콜 반복 수 기준 통과율이 높다.
- 공식 `realign` 부분 경계에서 평균·중앙 오차가 감소했다.
- 후보 없음과 다중 후보 구간을 QC 상태로 표시할 수 있다.
- 반복 수가 맞더라도 시간·각도 지표가 저자 기준과 달라질 수 있다.

### 보류

- 전체 STS 경계 정확도 향상
- 사람 검수 수요 제거
- 임상적으로 정확한 수행 시간 또는 관절 특징 산출
- 촬영 조건이 달라도 동일한 경계·특징 보장
- Kinect 또는 marker-based motion capture 대비 정확도

보류 주장을 검증하려면 독립적인 사람 경계 annotation 또는 동기화된 기준 장비 자료가 필요하다.

## 5. 실촬영 활용안

신규 참여자 촬영은 IRB 확인 전 진행하지 않는다. 기존 동일인 3개 영상은 end-to-end 동작 확인과 실패 사례 제시에만 사용한다. 향후 촬영이 허용되면 다음을 사전에 고정한다.

- 스마트폰과 기준 장비를 삼각대에 고정
- 측면과 정면이 함께 보이는 약 45도 배치
- 1.5~3 m 안에서 머리·발·의자 전체가 두 장비에 들어오는 거리를 실측해 고정
- 세로 영상, 밝은 확산광, 창문·직사광 역광 제외
- 팔을 가슴에 교차하고 5회 수행
- 시작·종료 시 완전히 앉은 상태를 각각 2~3초 포함
- 시작 시 박수 1회와 양쪽 timestamp로 동기화
- 촬영 직후 인체 검출률, 프레임 이탈, 관절 confidence, 반복 수, magnitude 후보 상태 확인
- 후보 없음·다중 후보·경계 잘림·심한 가림은 자동 확정하지 않고 수동 검수 또는 제외

## 6. 후속 데이터 연결

- Stanford 공개자료는 자동 분할 QC와 처리 실패 양상을 검증하는 주자료로 유지할 수 있다.
- 기존 313명·1,543회 시간축 자료는 324명 중 시간 QC 경고 11명을 제외한 후속 분석이다. 이번 경계 QC 결과와 `subjectid`로 연결하되, 5회를 독립 표본으로 늘리지 않고 참여자 내 반복으로 다룬다.
- 자동 분할 상태별로 첫 시행과 2~5회 곡선 결과가 유지되는지 민감도 분석할 수 있다. 이는 이번 검증과 별도 후속 실험이다.
- CeTI·REMAP 등은 STS 과제, 장비, label, 경계 정의가 달라 지금 합치면 표준화 자체가 새 연구가 된다. 경진대회 전에는 추가 다운로드·통합을 미루고 Stanford와 기존 실영상 범위에 집중한다.

## 8. 경진대회 적용

경진대회에서는 이 축을 `자동 국면 분할 완료`가 아니라 다음 순서로 제시한다.

1. 공개 코드는 일부 사람별 crop·경계 교정에 의존한다.
2. 반복 수 기반 자동 magnitude 선택으로 처리 성공률을 높였다.
3. 부분 수정 경계에서는 평균 오차가 감소했지만 실패·모호·악화 사례가 남았다.
4. 따라서 자동 결과에 후보 수와 실패 상태를 함께 내는 QC가 필요하다.
5. 완전한 정확도 평가는 향후 사람 annotation 또는 기준 장비 동기화 자료로 수행한다.

이 결과는 경진대회 파이프라인의 자체 개선 요소와 한계를 함께 보여줄 수 있지만, 진단 성능이나 임상 ground truth를 주장하는 근거는 아니다.
