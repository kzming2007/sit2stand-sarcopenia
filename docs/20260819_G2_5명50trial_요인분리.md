## 1. 설계한 세 대조 — 각각 한 요인만 바꿨다

`20260818` 에서 15 trial 을 세 개의 단일요인 대조로 배분했다. 결과:

```
              5STS 시간            Alcazar 상대파워        바뀐 것
P01    7.90 -> 6.01  (-24.0%)    4.76 -> 4.93  ( +3.7%)   의자 44 -> 53cm
P02    9.23 -> 6.76  (-26.8%)    4.07 -> 5.56  (+36.4%)   줌 0.6 -> 1.0배
P04   12.69 -> 8.99  (-29.2%)    2.08 -> 2.96  (+41.9%)   지시어 + 휴식
P05     신규 6.09                     6.90                신규(순진·표준지시)
```

세 사람 다 시간이 24~29% 줄었다. 처음에는 공통 "세션 효과"로 보였으나
**Alcazar 파워가 세 경우를 갈라놓았다.**

### P01 — 의자가 전부다

Alcazar 파워는 의자 높이를 이미 보정한 값이다(`d = 0.5×키 − 의자높이`).
의자가 원인이면 시간은 줄어도 파워는 그대로여야 한다.

```
상승거리   42.5cm -> 33.5cm    -21.2%
실측 시간   7.90초 -> 6.01초    -24.0%     차이 2.8%p
파워                            +3.7%     변화 없음
```

두 장비가 독립적으로 같은 답을 냈다.

```
폰       시간 -24.0%   파워 +3.7%
Kinect   시간 -24.0%   파워 +3.7%
```

**본인이 강해진 것이 아니라 의자가 일을 덜 시켰다.**

### P02 — 사람이 달라졌다

줌은 카메라 속성이라 사람이 얼마나 빨리 일어서는지를 바꿀 수 없다. 그런데
파워가 **+36.4%** 늘었다. 실제 역학적 출력이 늘어난 것이다. 피험자 본인이
"익숙해져서 더 빨리 했다"고 보고한 것과 일치한다.

### P04 — 지시어가 컸다

파워 **+41.9%**. 세션 1 에는 "최대한 빠르게" 지시가 없었고 세션 2 에는 있었다
(촬영자 확인). 지시어 하나가 파워를 40% 움직인다.

> 이 분리는 우연이 아니다. `20260818` 에서 15 trial 을 **한 세션에서 요인 하나씩만
> 바꾸도록** 배분했기 때문에 가능했다. 전원을 53cm 로 통일했다면 셋 다 못 얻었다.

### 정정 기록

분석 도중 P02 를 "세션 효과 대조군"으로 삼아 P01·P04 를 보정했고, 그 결과
의자 효과를 +3.8%(거의 0)로 잘못 결론지었다. P02 의 변화는 공통 세션 효과가
아니라 P02 개인의 노력 증가였으므로 대조군이 아니었다. **파워를 보고 나서야
갈렸다.**

## 2. 의자 높이 — 원 시간은 흔들리고 파워는 안 흔들린다

`시간 ∝ 상승거리` 로 53cm 측정치를 표준 44cm 로 환산하면:

| | 53cm 실측 | 44cm 환산 |
|---|---|---|
| 어머님 (여 58세) | 8.42초 | **11.57초** |
| 아버님 (남 62세, 세션2) | 8.99초 | **11.70초** |
| 아버님 (세션1, 지시어 없음) | 12.69초 | 16.51초 |

**두 분 다 AWGS 12초 경계 바로 아래다.** "정상"이 아니라 "경계선"이다.
`20260818` 에서 아버님을 8.99초 근거로 "소견 아님"이라 쓴 것은 53cm 측정치를
표준 절단값에 그대로 댄 오류였다.

환산은 Alcazar 의 등속 가정에 기댄 것이고 검증 사례가 P01 하나(오차 2.8%p)뿐이다.
참고값으로 쓴다.

의자에 강건한 파워로 보면 두 분 다 무난하다.

```
어머님  2.53 W/kg     문헌 약 75세 여  2.0±0.6
아버님  2.96 W/kg     문헌 약 75세 남  2.6±0.7
```

> **보고 방침**: 대상 간 비교와 절단값 판정에는 **원 5STS 시간 대신 Alcazar 상대
> 파워**를 쓴다. 같은 사람에서 의자만 바꾼 통제 실험으로 근거를 확보했다.
> 원 시간을 쓸 때는 의자 높이를 반드시 병기한다.

## 3. 줌 실험 — 영향 없다

P02 를 0.6배 10 trial, 1.0배 5 trial 로 대조했다(같은 사람).

| 지표 | 0.6배 | 1.0배 | 차이 | t | |
|---|---|---|---|---|---|
| trunk_lean_max | −3.72 | −6.63 | −2.91 | −1.96 | ns |
| trunk_lean_range_mean | −5.80 | −7.39 | −1.59 | −1.28 | ns |
| left_hip_range_mean | −9.39 | −1.90 | +7.49 | 1.52 | ns |
| right_hip_range_mean | −8.07 | −4.57 | +3.51 | 1.33 | ns |
| left_knee_range_mean | −9.16 | −10.18 | −1.02 | −0.27 | ns |
| right_knee_range_mean | +0.66 | +0.69 | +0.03 | 0.01 | ns |

(df=13, t 절댓값 > 2.16 이면 p<0.05)

**하나도 유의하지 않다.** `20260818` §6 의 검출력 계산에서 이 설계로 잡을 수
있다고 본 trunk_lean_max(MDE 2.31°)에서도 관측차 −2.91°, t=−1.96 으로
경계에 걸렸다.

한계: 이 세션에서 P02 의 동작 자체가 바뀌었다(파워 +36.4%). 줌과 노력이 섞여
있으므로 "줌 효과 없음"은 잠정 결론이다. 확정하려면 **한 세션 안에서 0.6/1.0 을
번갈아** 찍어야 한다.

다만 §4 가 더 중요한 답을 준다 — 편향을 흔드는 것은 줌이 아니다.

## 4. 핵심 — 각도 오차의 대부분은 장비가 아니라 촬영 세팅이다

LoA 폭을 세션 내 잡음과 세션 간 편향 차이로 분해했다(8개 사람×세션 조합).

| 지표 | 전체 LoA폭 | 세션내 잡음 | 세션간 편향 | **편향 비중** |
|---|---|---|---|---|
| time | 0.90 | 0.95 | 0.24 | **6%** |
| time_sit2stand | 1.01 | 1.02 | 0.37 | **11%** |
| alcazar_rel_power_Wkg | 0.24 | 0.24 | 0.11 | **18%** |
| trunk_lean_max | 18.33 | 7.76 | 17.41 | **83%** |
| trunk_lean_range_mean | 16.24 | 7.28 | 15.53 | **82%** |
| left_knee_range_mean | 52.22 | 32.42 | 48.91 | **69%** |
| left_hip_range_mean | 44.39 | 29.85 | 37.96 | **62%** |
| right_hip_range_mean | 30.64 | 19.26 | 23.20 | **59%** |
| right_knee_range_mean | 19.01 | 16.98 | 12.04 | **33%** |

같은 사람도 세션이 바뀌면 편향이 통째로 이동한다.

```
P01  left_knee 편향   S1 −20.99   ->   S2 −38.30
P04  left_hip  편향   S1  +0.84   ->   S2 −10.53
P04  right_knee 편향  S1  −1.43   ->   S2  −8.09
```

**따라서:**

- 각도는 **한 번 보정해서 재사용할 수 없다.** 보정 상수가 세션마다 달라진다
- `20260818` 에서 "편향이 사람마다 다르다"고 한 것은 절반만 맞았다.
  **사람이 아니라 세션이다.** 같은 사람도 다시 찍으면 달라진다
- 각도를 쓰려면 **카메라 배치의 엄격한 표준화**가 선행돼야 한다.
  현재 프로토콜로는 각도 지표를 임상 지표로 제안할 수 없다
- 시간·파워는 이 문제에서 자유롭다(6%, 18%)

## 6. 프로토콜 확정

이번 세션에서 확인된 것을 반영한다.

| 항목 | 값 | 근거 |
|---|---|---|
| 의자 높이 | **44cm 고정** | 9cm 가 시간을 24% 움직인다 (§2) |
| trial 수 | **5회** | 세션1 에서 T05 최속, T06~T10 은 피로 구간 |
| 시행 간 휴식 | **60초 이상** | `20260818` §1 |
| 연습 시행 | **1~2회 후 60초 휴식** | 세션 간 파워 +36% (§1). 순진↔숙련 차이 흡수 |
| 지시어 | "최대한 빠르게, 팔은 가슴에 교차" | 파워 +41.9% (§1) |
| 회수 세기 | 촬영자가 소리 내어 | P03_T01 4회 사례 |
| 카메라 | 높이·거리·각도 기록 필수 | 각도 오차의 59~83% 가 세팅 탓 (§4) |

### 연습 시행이 필요한 이유

임상에서 5STS 를 받는 환자는 연습을 안 한 상태이고 AWGS 12초도 그런 사람들로
맞춘 값이다. 숙련된 상태로 재면 실제보다 빠르게 나와 **과소검출**된다.
연습 시행을 표준화하면 순진과 숙련의 차이가 흡수된다.

P05 만이 순진 + 표준지시로 제대로 측정된 유일한 사례다. **신규 피험자는 첫
세션에서 제대로 재야 한다 — 두 번째 기회는 이미 숙련된 사람이다.**

## 7. 재현

```bash
bash logs/run_s2_phone.sh
bash logs/run_s2_kinect.sh

for s in P01_S2 P02_S2 P04_S2 P05; do
  for t in 01 02 03 04 05; do
    python scripts/pair_trials.py \
      --phone results/desktop/g2_phone_${s}_T${t}.npy \
      --kinect results/desktop/${s}_T${t}_kinect.npy \
      --phone-json results/desktop/g2_phone_${s}_T${t}.json \
      --kinect-json results/desktop/${s}_T${t}_kinect.json \
      --subject ${s} --id T${t} --out results/g2_pairs_${s}.csv
  done
done

# 같은 사람은 같은 subject 로 묶는다
head -1 results/g2_pairs_4subj.csv > results/g2_pairs_5subj.csv
tail -n +2 results/g2_pairs_4subj.csv >> results/g2_pairs_5subj.csv
for s in P01_S2 P02_S2 P04_S2 P05; do
  base=$(echo $s | sed 's/_S2//')
  tail -n +2 results/g2_pairs_${s}.csv | sed "s/^${s},/${base},S2_/" \
    >> results/g2_pairs_5subj.csv
done
python scripts/phase3_agreement.py --pairs results/g2_pairs_5subj.csv
```

전량 데스크톱(RTX 5060). Kinect 는 GPU 에 따라 값이 달라진다(`20260817`).
