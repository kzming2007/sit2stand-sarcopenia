## 1. G3 지표 확장 — 영상 재처리 없이

Phase 4 의 M2 는 각속도·수직속도·좌우비대칭으로 이루어져 있는데, 이 열들은
`pair_trials.PAIR_METRICS` 에 없어 **G3 등급이 없었다.** 등급이 없으면 거를 수
없으므로 먼저 채웠다.

값은 이미 50 trial 전부에 산출돼 있었다. `pair_trials.py` 의 JSON 전용 모드로
짝만 다시 만들면 되고 **영상 재처리가 필요 없다**(수 분).

```
지표 12개 -> 22개 · 50 trial · 5명   (results/g2_pairs_5subj_ext.csv)
```

## 2. M2 재구성

G3 등급이 '높음' 또는 '보통'인 것만 남겼다.

```
통과 : trunk_lean_max            (보통, ICC 0.799)
제외 : 11개 (위 표 + trunk_lean_range_mean 0.672)

M2 특징 수   16개 -> 5개   (인구통계 3 + 총시간 1 + trunk_lean_max 1)
```

**M2 가 사실상 한 개 특징으로 줄었다.** 이것 자체가 결과다 — 현재 스마트폰
단일 뷰로 안정적으로 잴 수 있는 비시간 운동학 지표는 체간 각도 하나뿐이다.

## 3. 결론이 바뀐 지점

RandomForest, 5-fold × 3회 반복.

| 결과변수 | 대조 | 1차 pass (운동학 12개) | 2차 pass (G3 통과분) |
|---|---|---|---|
| GPH_TScore | ΔM1−M0 | +0.0422 [+0.025, +0.060] 유의 | +0.0422 [+0.025, +0.060] 유의 |
| GPH_TScore | ΔM2−M1 | +0.0011 불확실 | −0.0060 불확실 |
| GPH_TScore | ΔM3−M2 | +0.0071 불확실 | **+0.0206 [+0.004, +0.038] 유의** |
| GMH_TScore | ΔM3−M2 | −0.0049 불확실 | **−0.0174 [−0.029, −0.005] 역방향** |
| **fallsBin** | **ΔM2−M1** | **−0.0108 불확실** | **+0.0365 [+0.017, +0.056] 유의** |
| fallsBin | ΔM3−M2 | −0.0114 불확실 | **−0.0528 [−0.080, −0.026] 역방향** |
| OA_check | ΔM2−M1 | +0.0073 불확실 | −0.0024 불확실 |

ΔM1−M0 이 두 pass 에서 완전히 동일하다. M0·M1 은 필터의 영향을 받지 않으므로
**정상 동작 확인**이 된다.

### 선형 모델에서도 같은 방향

| 결과변수 | 대조 | 1차 pass | 2차 pass |
|---|---|---|---|
| **fallsBin** | ΔM2−M1 | **−0.0552 [−0.100, −0.011] 역방향** | **+0.0071 불확실** |
| OA_check | ΔM2−M1 | −0.0084 불확실 | +0.0064 [+0.000, +0.012] 유의 |
| GPH_TScore | ΔM3−M2 | +0.0071 유의 | +0.0070 유의 |

낙상 이력의 ΔM2−M1 이 forest 에서 **+0.047**, linear 에서 **+0.062** 만큼
개선 방향으로 이동했다. 모델을 바꿔도 방향이 같다.

## 4. 해석

1차 pass 의 결론은 **"비시간 운동학은 총 시간 위에 기여하지 않는다"** 였다.
2차 pass 는 그 문장을 이렇게 고친다.

> 기여하지 않은 것은 **지표가 무의미해서가 아니라, 그중 11개가 애초에
> 재현되지 않는 값이었기 때문**이다. 잡음 11개를 빼자 남은 한 개가 낙상
> 이력에서 유의한 기여를 보였다.

이것이 이 프로젝트의 두 축이 만나는 지점이다. 자체 촬영으로 얻은 **측정
신뢰도**가 공개 데이터의 **예측 분석**에서 특징 선별 기준이 됐고, 그 결과
선행 연구의 결론 하나가 바뀌었다.

### 방법론적 진술

**측정 신뢰도 검증 없이 특징을 넣으면 증분가치 분석의 결론이 달라진다.**
1차와 2차는 같은 데이터·같은 모델·같은 fold 를 쓰고 오직 M2 구성만 다르다.

## 5. 한계 — 반드시 함께 보고할 것

### (1) 신뢰도 등급의 전이 가정

G3 등급은 **우리 5명의 촬영 조건**에서 나왔고, 이를 **다른 조건에서 수집된
405명**의 특징을 거르는 데 썼다. 조건이 다르면 등급도 달라질 수 있다.

특히 `20260819` §4 에서 **각도 오차의 62~83% 가 촬영 세팅에서 온다**는 것을
확인했으므로, 등급 자체가 조건 의존적이다.

다만 방향은 보수적이다. 공개 데이터는 **참여자 각자가 자기 폰으로 집에서**
찍은 것이라 세팅 변동이 우리보다 **크다.** 우리 등급은 그쪽에 대해
낙관적인 추정치이지 비관적인 추정치가 아니다.

### (2) 반복 교차검증 fold 신뢰구간은 비보수적이다

fold 들이 데이터를 공유하므로 표준오차가 과소추정된다. `20260805` 에서
이미 지적한 사항이며 **"유의" 표기를 통상적 유의성으로 읽으면 안 된다.**

### (3) 표본

낙상 양성 34/405 (8.4%), OA 양성 30/405 (7.4%). AUC 의 fold 간 표준편차가
0.13 수준으로 크다. ΔAUC +0.0365 는 절대 크기가 작다.

### (4) 사전등록 밖

확장한 10개 지표의 일치도는 사전등록 기대치표에 없다. 탐색적이다.

### (5) 65세 이상

공개 데이터에도 65세 이상은 46명뿐이다(11%). 대상 집단에 대한 결론이 아니다.

## 6. 부수 수정 — `.json` 과 `.txt` 불일치

델타(ΔR²/ΔAUC 와 신뢰구간)가 화면에만 찍히고 JSON 에는 안 들어가서 두 산출물이
어긋나 있었다. 인수인계 문서에 미해결로 적혀 있던 항목이다.

```json
{ "GPH_TScore": {
    "scores":  { "M0": {...}, "M1": {...} },
    "deltas":  { "M2-M1": {"delta":  -0.0060, "lo": -0.0245,
                           "hi": 0.0125, "verdict": "불확실"} },
    "n_features": { "M0": 3, "M1": 4, "M2": 5, "M3": 8 } } }
```

이제 `.json` 만으로 `.txt` 의 모든 수치를 재구성할 수 있다.

## 7. 재현

```bash
# 1) 지표 확장 후 짝 재생성 — 영상 재처리 없음
bash logs/rebuild_pairs.sh
python scripts/phase3_agreement.py --pairs results/g2_pairs_5subj_ext.csv

# 2) Phase 4 두 pass
python scripts/phase4_incremental.py --model forest --repeats 3 --tag _pass1
python scripts/phase4_incremental.py --model forest --repeats 3 --tag _pass2 \
       --g3 results/phase3_5subj_ext/agreement.csv
# linear 도 동일하게
```

`--g3` 를 주면 2차 pass, 안 주면 1차 pass 다. `--g3-allow` 로 통과 등급을
바꿀 수 있다(기본 `높음,보통`).

## 8. 보고서에 넣을 문장

> 선행 연구의 공개 데이터(405명)에서 동작 품질 지표의 증분가치를 계단식 모델로
> 비교하였다. 1차 분석에서는 이론적 근거로 선별한 비시간 운동학 12개를
> 사용하였으나, 자체 수집한 50 trial 의 장비 간 일치도 분석 결과 이 중 11개의
> ICC 가 0.43 이하(3개는 음수)로 재현성이 확보되지 않았다. 신뢰도 등급이
> '높음' 또는 '보통'인 지표만으로 M2 를 재구성한 2차 분석에서 낙상 이력에 대한
> ΔAUC 가 −0.011 에서 +0.037 로 이동하였다(선형 모델에서도 −0.055 → +0.007로
> 같은 방향). 측정 신뢰도 검증 없이 특징을 구성하면 증분가치 분석의 결론이
> 달라질 수 있음을 보인다. 다만 신뢰도 등급이 우리 촬영 조건에서 산출된 값이며
> 반복 교차검증의 신뢰구간이 비보수적이라는 한계가 있다.
