`불일치` 14개도 실질적 차이가 아니다. 최대 상대오차가 **0.34%** 이고, 456명 중 1~24명에서만 발생했다.

공통 특징이 있다. **모두 가속도·속도 계열, 그리고 국소 극값(min/max) 지표다.** 미분 연산과 극값 탐색은 부동소수점 반올림에 민감하고, 극값 위치가 한 프레임 이동하면 값이 튄다. NumPy·SciPy 버전 차이로 설명되는 수준이며 알고리즘 불일치가 아니다.

**해석**: 도메인 문서 Part 4에서 다룬 "미분이 노이즈를 증폭한다"가 재현 단계에서 실측으로 확인됐다. 사전등록 기대치표에서 각가속도 ICC를 0.40–0.70으로 낮게 잡은 근거가 보강된다.

### 3.2 dataClean.csv 와 dataClean_text.csv 는 다른 버전 (주의 필요)

| | 행 | 열 | 5STS 평균 |
|---|---|---|---|
| `dataClean.csv` | 405 | 738 | **11.40초** (논문과 일치) |
| `dataClean_text.csv` | 405 | 700 | 11.13초 |

두 파일의 `time` 값이 **405행 중 47행에서 다르다.** 같은 코호트인데 지표값이 다르므로 서로 다른 시점의 export다.

동시에 중요한 사실이 있다. `framerate`와 `Age`가 **405/405 행 단위로 일치한다.** 즉 두 파일은 **동일한 행 순서**를 갖는다.

이게 실용적으로 필요한 이유: `dataClean.csv`는 `subjectid`가 전부 `'0'`으로 익명화되어 있고, `dataClean_text.csv`만 원본 8자 ID를 유지한다. 행 순서가 같으므로 **행 인덱스로 ID를 복원할 수 있다.**

```python
import pandas as pd
dc   = pd.read_csv('stats/dataClean.csv')        # 분석용 (논문 일치)
text = pd.read_csv('stats/dataClean_text.csv')   # ID 공급용
dc['subjectid'] = text['subjectid'].values       # 행 순서 정렬 확인됨
```

**규칙으로 고정할 것**

- 분석 기준 데이터는 **`dataClean.csv`** 하나만 쓴다 (논문 재현되는 버전)
- `dataClean_text.csv`는 **`subjectid` 열만** 가져온다. 지표값은 쓰지 않는다
- 두 파일의 지표를 섞으면 47행에서 조용히 다른 값이 들어간다

`orientation` 열은 행 단위 일치가 0/405인데, `dataClean.csv`는 숫자 코드(0), `_text` 버전은 문자 라벨을 쓰기 때문이다. 파일명의 `_text`가 범주형 변수의 텍스트 표기를 의미한다. 오류가 아니다.

## 4. 최종 보고서용 정리 문구

> 선행 연구(Boswell et al., 2023)의 공개 코드와 익명화 궤적을 이용해 특징 추출 파이프라인의 재현성을 검증했다. 공통 456명 × 535개 지표 중 497개가 부동소수점 정밀도 내에서 완전히 일치했고, 나머지 38개도 최대 상대오차 0.34% 이내였다. 불일치는 모두 속도·가속도 및 국소 극값 계열에 국한되어 수치 미분의 반올림 민감도로 설명된다. 주력 지표인 5회 STS 시간은 324명 공통 표본에서 최대 절대차 4.68×10⁻⁹초로 재현되었으며, 전체 코호트 평균은 11.40±3.43초로 원 논문 보고값(11.4±3.4초)과 일치했다.
