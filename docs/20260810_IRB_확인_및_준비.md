## 1. IRB 가 무엇인가

**IRB(Institutional Review Board, 기관생명윤리위원회)** 는 사람을 대상으로 하는 연구가 윤리적으로 타당한지 사전에 심의하는 기구다. 「생명윤리 및 안전에 관한 법률」(생명윤리법)에 근거한다.

핵심은 **연구 시작 전에** 승인을 받아야 한다는 것이다. 데이터를 먼저 모으고 나중에 승인받는 것은 인정되지 않는다.

심의하는 것은 대략 이런 것들이다.

- 참여자에게 위험이 있는가, 있다면 통제되는가
- 참여자가 충분히 설명을 듣고 **자발적으로** 동의했는가
- 개인정보를 어떻게 보호하는가
- 참여자가 언제든 그만둘 수 있는가

---

## 2. 우리 연구는 어디에 해당하는가

**두 부분을 나눠서 봐야 한다.** 이 구분이 핵심이다.

| 작업 | 성격 | IRB |
|---|---|---|
| Phase 1·4, Tier 2 — **공개 데이터 분석** | 익명화된 **2차 자료** | 🟢 문제 없음 |
| Phase 2 — **자체 촬영** | 사람에게 직접 개입 + **얼굴·신체 영상** | 🔴 **심의 필요** |

지금까지 한 분석(Boswell 405명 공개 데이터, 독립 구현 검증, 강건성 분석)은 **이미 익명화되어 공개된 2차 자료**를 쓴 것이라 심의 대상이 아니다. **여기까지는 아무 문제가 없다.**

문제는 Phase 2다. 동작 영상에는 얼굴과 신체가 담기므로 **개인식별정보**이고, 사람에게 직접 과제를 수행시키는 개입이 있다.

> 가톨릭대 IRB 안내의 심의면제 대상은 **"2차 자료를 사용하는 인간대상연구"** 및 보관된 인체유래물 연구다. **직접 촬영은 여기 해당하지 않는다.**

## 7. 심의를 못 받는 경우 — 축소 경로

계획서 §6의 게이트 미통과 대응을 준용한다. **이 경우에도 연구는 성립한다.**

| 유지되는 것 | 근거 |
|---|---|
| G1 독립 구현 재현 (217명, r=1.0000) | 공개 2차 자료 |
| G4 증분가치 분석 | 공개 2차 자료 |
| Tier 2 강건성 분석 | 공개 2차 자료 |
| 논문 공개 코드의 산출 정의 오류 발견 | 공개 코드 감사 |
| MediaPipe 파이프라인 구현 | **연구팀 본인 영상만 사용** |

| 포기되는 것 | 영향 |
|---|---|
| G2 동시 촬영 30 trial | RQ1(스마트폰 vs Kinect 일치도) 불가 |
| G3 지표별 신뢰도 등급 | Phase 4 2차 pass의 특징 선별 근거 상실 |

**RQ1을 "재현성 검증"으로 대체**하고, 계획서 §6의 `G0 실패 → 스마트폰 단독 + 공개 데이터로 설계 축소` 경로를 그대로 적용한다. 한계 항목에 사유와 함께 명시한다.

> **연구팀 본인만 촬영하는 경우**의 심의 필요 여부도 문의에 포함했다. 이 경로가 열리면 MediaPipe 실영상 검증과 Kinect 동시 촬영을 최소 규모로나마 수행할 수 있다.
