# 통합 진행 상황 및 다음 작업

기준일: 2026-08-10

## 현재까지 확인된 상태

### 저장소 작업

- **G0:** Kinect 환경과 Body Tracking 확인 절차를 마련했고, 저장소 기록 기준 1·2단계를 통과했다. 3단계는 거리·전신 화각·역광을 보정한 인체 검출 확인이 남아 있다.
- **G1:** Boswell et al. 특징 계산을 독립 구현했고, 공식 코드의 피험자별 처리·검토·제외 목록에 없는 217명에서 13개 지표를 완전히 재현했다. 이는 계산 파이프라인의 재현이며 외부 장비 대비 측정 정확도 검증은 아니다.
- **G4 1차:** 405명 요약자료에서 인구통계, 5STS 총 시간과 비시간 동작 특징의 증분가치를 비교했다. 총 시간은 GPH 설명에 소폭 기여했지만 기존 비시간 요약 특징의 추가 기여는 안정적으로 확인되지 않았다.
- **MediaPipe 계층:** `scripts/mediapipe_pose.py`와 `scripts/sts_metrics.py`가 추가됐다. 영상부터 지표까지 이어지는 새 파이프라인은 코드가 완성됐지만 실제 영상 end-to-end 검증은 남아 있다.
- 골관절염·낙상 결과는 양성 표본과 연령 구조의 제한이 커 주결과로 사용하지 않는다.

### 별도 로컬 작업

- 직접 촬영 영상에서 기존 MediaPipe pose, STS 구간과 특징을 추출하는 demo를 구현했다. 저장소의 새 `mediapipe_pose.py`와는 아직 실행 결과를 대조하지 않았다.
- Stanford pose trajectory 연결 대상 324명의 반복 경계를 감사했다.
- 시간 경계 QC 경고 11명을 제외한 313명, 1,543개 기립 시행을 0~100%로 정규화했다.
- 첫 시행은 2~5회와 시작 조건과 시간축 형태가 달라, 5회를 독립 표본이나 단순 데이터 증강으로 취급하지 않는다는 처리 기준을 확인했다.
- 첫 시행과 2~5회 특징을 GPH에 추가하는 최종 비교는 아직 실행하지 않았다.

## 두 분석의 역할

- 현재 저장소의 `M0~M3` 분석은 참여자별 **요약 특징의 기준 분석**이다. 문서에서는 `B0~B3`로 구분한다.
- 로컬 반복 분석은 기존 요약 방식의 한계를 보완할 수 있는 **후속 후보**다. 실행 시 `R0~R2`로 구분한다.
- 두 결과는 충돌하지 않는다. 현재까지는 총 수행 시간 위에 동작 특징을 단순 추가하는 것만으로 GPH 예측이 안정적으로 개선되지 않았다는 방향이 공통적이다.

## 결과 해석 기준

1. `GPH_TScore`는 일반적인 자기보고 신체건강 점수이며 근감소증 진단 label이 아니다.
2. `5STS 12초 이상`은 총 수행 시간에서 만든 기준이다. 전체 연령의 독립적인 임상 진단 결과가 아니라 `12초 초과 여부`로 기술한다.
3. Kinect는 ground truth가 아니라 스마트폰과 비교할 기준 장비다.
4. 반복 교차검증 fold를 독립 표본으로 간주한 신뢰구간은 과도하게 좁을 수 있으므로 participant 단위 재검증이 필요하다.
5. Alcazar power는 공개자료의 의자 높이와 신축 국면 비율을 가정하므로 절대값을 핵심 성과로 사용하지 않는다.

## 경진대회 우선순위

1. **MediaPipe 실영상 검증:** 기존 직접 촬영 영상으로 저장소의 새 파이프라인을 실행하고 국면 분할·지표 출력·실패 원인을 확인한다.
2. **Kinect 동작 확인 완료:** 거리·전신 화각·역광을 보정해 Body Tracking 3단계를 끝내고 저장 형식을 확정한다.
3. **동시 촬영 계약 고정:** 스마트폰·Kinect 동기화, 의자 높이, 카메라 위치, 반복 횟수와 제외 기준을 문서화한다.
4. **G2 자료 수집:** 연구 참여·동의 절차를 확인한 뒤 계획한 동시 촬영 trial을 확보하고 원본은 저장소 밖에서 관리한다.
5. **G3 방법 비교:** 수행 시간, 몸통 기울기, 무릎 각도와 상승 관련 지표 중 양쪽 장비에서 같은 의미로 계산할 수 있는 값의 오차·일치도·실패 사례를 평가한다.
6. **G4 2차 분석:** G3에서 신뢰도가 확인된 특징만 사용해 공개자료 증분가치 분석을 다시 실행한다. participant 단위 불확실성 평가를 함께 보정한다.
7. **후속 판단:** Kinect 일정이 지연되거나 기존 요약 특징의 개선 근거가 필요하면 `R0~R2` 반복 시간축 비교를 실행한다.
8. **결과물:** 재현 코드, 공개자료 결과표, 장비 비교 그림, skeleton·시간축 시각자료, 실패 사례, 간단한 demo, 최종 보고서와 10분 발표자료를 준비한다.

웹·앱의 완성도보다 검증 결과와 발표에서 설명 가능한 그림을 우선한다.
