## 1. 서론

### 1.1 연구 배경

초고령사회에서 근감소증(Sarcopenia)은 낙상·골절·신체기능 저하로 이어지는 대표적 노인성 질환이다. 국내 지역사회 70세 이상 대상 조사에서 AWGS 2019 기준 유병률은 남성 14.4%, 여성 6.4%로 보고되었다. 질병관리청은 2019년부터 AWGS 2019 기준에 따른 악력 저하율을 국민건강영양조사에 포함하고 있으며, 2022년부터 생체전기저항분석(BIA)을 도입해 근육량 기반 유병률을 산출하고 있다.

근감소증의 표준 진단은 세 축을 조합한다. **근육량**(DXA·BIA), **근력**(악력계), **신체기능**(보행속도·의자 일어서기)이다. 이 중 근육량과 근력은 전용 장비를 요구하나, 신체기능은 도구 없이 측정 가능하다. AWGS 2019는 신체기능 저하 기준으로 6m 보행속도 1.0 m/s 미만, SPPB 9점 이하, **5회 의자 일어서기(5STS) 12초 이상**을 제시한다.

즉 국제 합의 기준 중 하나가 초시계만으로 측정 가능한 형태로 존재한다. 여기에 컴퓨터 비전을 결합하면 측정 자체를 자동화·객관화할 수 있다.

### 1.2 선행 연구 검토

**Boswell et al. (2023), npj Digital Medicine** — 본 연구의 직접적 기반이다. 미국 35개 주 405명이 가정에서 스마트폰으로 5회 STS를 자가 촬영했고, OpenPose 2D 자세추정으로 운동학 지표를 산출해 골관절염 진단·PROMIS 신체정신건강·BMI·연령과의 연관성을 분석했다. 검증된 사실은 다음과 같다.

- **시간 지표는 2D 영상으로 매우 정확하게 측정된다.** 실험실 마커 기반 모션캡처(8카메라·31마커·100Hz) 대비 검사 시간 상관 r=0.997
- **각도 지표는 그렇지 않다.** 체간각 대 요추 굴곡 r=0.583, 요추 측굴 r=0.702, 체간 각가속도 r=0.556
- 체간 전방경사가 골관절염 진단과 유의하게 연관(R=0.18, 보정 β=0.029, p=0.015). 하지 근력 부족의 보상 동작으로 해석
- 실험실 검증 표본은 n=11(평균 27.7세)
- 저자가 명시한 한계: 의자 높이·발 위치 미통제, 45° 시야의 평면 혼합, 헐렁한 의복·고BMI에서 골반 추정 오류로 **84개 영상 제외**

이 연구는 **가설 검정 중심이며 머신러닝 예측 모델을 구축하지 않았다.** 상관분석과 회귀분석(FDR 보정)만 수행했다. 따라서 예측 모델링은 미개척 영역으로 남아 있다.

**Chan et al. (2026), Communications Medicine** — 같은 문제에 딥러닝을 적용한 후속 연구다. 309명의 측면(sagittal) STS 영상 2,063건에서 체간·무릎·발목 각도 및 각속도의 시공간 상호작용을 학습하는 `STS Dynamics Net`으로 증상성 무릎 골관절염을 판별해 **AUC 0.7759±0.0219**를 얻었고, 관절 각속도가 견고한 시공간 바이오마커라고 보고했다.

두 가지를 시사한다. 첫째, **각속도 지표에 신호가 있다.** 둘째, 2,063건 영상 + 딥러닝으로도 AUC가 약 0.78이다. 405명 표본에서 0.9 이상을 기대하는 것은 비현실적이며, 그런 값이 나오면 누출을 의심해야 한다.

**Alcazar et al. (2018), Exp Gerontol** — 5STS 시간·체중·신장·의자높이만으로 하지 근파워를 추정하는 식을 제시했다. 선형변위계·Nottingham power rig·force plate 3종에 대해 60–93세 718명으로 검증되었다. Baltasar-Fernandez et al. (2021)이 4개 후보식을 1,568명에서 비교한 결과, Alcazar 식이 노쇠·저악력 판별력에서 가장 우수했다(AUC 0.68–0.80).

근파워는 근육량·근력보다 더 이른 나이에 더 빠르게 감소하며, 일상 동작 수행능력과의 연관이 더 강하다. 조기 신호로서 민감도가 높다는 뜻이다.

**Jo et al. (2022), Sensors** — Azure Kinect와 마커 기반 모션캡처의 일치도를 평가했다. 정면 스쿼트 무릎각 ICC 0.90–0.91, 측면 스쿼트에서 가려진 쪽 무릎 ICC 0.66·고관절 ICC 0.64로 보고했다. 결론은 "신체 분절이 보이는 경우 중등도–양호, 가려진 부위의 정확도는 여전히 우려"였다.

**주의: 이 연구는 스쿼트·런지·리치를 시험했고 sit-to-stand는 포함하지 않았다.** STS 동작에 대한 Azure Kinect의 일치도 자료는 상대적으로 희박하다. 이는 두 가지를 의미한다 — Kinect를 STS의 Ground Truth로 전제할 근거가 부족하고, 동시에 그 공백 자체가 본 연구의 기여 지점이 된다.

### 1.3 본 연구의 차별점

선행 연구를 반복하지 않는 지점을 명시한다.

| 항목 | 선행 연구 | 본 연구 |
|---|---|---|
| 의자 높이 | 참가자 임의 선택, 저자가 한계로 명시 | **실측·기록.** Alcazar 식 입력이자 STS 시간의 주요 교란변수 |
| 비교 장비 | 실험실 마커 기반(n=11, 단일 세션) | Azure Kinect 3D 스켈레톤. **STS에 대한 Kinect 일치도 자료 자체가 기여** |
| 자세추정 | OpenPose (서버급 GPU 필요) | **MediaPipe Pose** (온디바이스 실시간 가능) — 실사용 가능성 검증 |
| 파워 지표 | 산출하지 않음 | **Alcazar 상대 STS 파워(W/kg)** + AWGS 임계값 대조 |
| 예측 모델 | 없음(상관·회귀만) | **증분가치 설계**(M0→M1→M2)로 동작 품질 지표의 추가 설명력 정량화 |
| 결과 제시 | 연구 결과 보고 | 지표별 **신뢰도 등급을 화면에 노출**하는 선별 시스템 |

## 2. 연구 목표 및 연구 질문

**목표**: 스마트폰 단일 2D 영상으로 산출한 STS 지표가 어느 수준까지 신뢰할 수 있는지 정량적으로 규명하고, 신뢰 가능한 지표에 한해 근감소증 선별 활용 가능성을 검증한다.

### 연구 질문과 가설

**RQ1 (측정 타당도)** — 스마트폰 2D 영상 기반 STS 지표는 Azure Kinect 3D 측정과 어느 정도 일치하는가?

> 가설 H1: **시간 계열 지표는 높은 일치도(ICC>0.90), 각도 계열은 중등도(ICC 0.50–0.80)를 보이며, 각가속도가 가장 낮다.**
> 근거: 선행 연구 마커 기반 대비 시간 r=0.997 대 체간각 r=0.583–0.702. 각가속도는 2회 미분으로 노이즈가 증폭된다.

**RQ2 (파워 추정)** — 영상에서 자동 산출한 5STS 시간으로 계산한 Alcazar 상대 파워가 문헌 참조 범위 내에 있는가?

> 가설 H2: 20대 건강 성인에서 문헌의 75세 참조치(남 2.6±0.7, 여 2.0±0.6 W/kg)보다 높은 값이 산출되며, Kinect 시간 기반 계산값과 ICC>0.85로 일치한다.

**RQ3 (증분가치)** — 5STS 시간에 동작 품질 지표를 추가하면 저신체기능·신체건강 예측이 개선되는가?

> 가설 H3: 체간 전방경사와 관절 각속도가 시간 지표 대비 추가 설명력을 가진다.
> 근거: Boswell(2023)에서 체간각이 시간·연령·성별·BMI 보정 후에도 골관절염과 유의(β=0.029, p=0.015). Chan(2026)에서 각속도가 견고한 바이오마커로 보고.

**RQ3은 개선이 없어도 유효한 결과다.** 그 경우 결론은 "2D 영상의 가치는 동작 품질 지표보다 시간 측정의 자동화·객관화에 있다"가 되며, 이는 RQ1의 H1(시간 지표 높은 일치도)과 정합적이다. 어느 방향이든 해석 가능한 설계다.

## 3. 연구 방법

### 3.1 전체 설계

5개 Phase를 순차 진행하며, 각 Phase 종료 시 **게이트(G)** 를 통과해야 다음 단계로 넘어간다.

```
Phase 0  환경·윤리 준비        → G0 Kinect 스켈레톤 저장 성공
Phase 1  선행 연구 재현        → G1 논문 지표 재현 (시간 오차<0.1s, 각도 r>0.95)
Phase 2  동시 촬영 데이터 수집  → G2 30 trial 확보
Phase 3  측정 타당도 분석       → G3 신뢰 가능 지표 확정
Phase 4  증분가치 분석         → G4 M0/M1/M2 비교 완료
Phase 5  시스템 구현·통합       → G5 end-to-end 통과
```

**Phase 1을 Phase 2보다 앞에 둔 것이 v1과의 가장 큰 차이다.** 특징 추출 코드가 검증되지 않은 상태로 자체 데이터를 수집하면, 코드 수정 시 전량 재분석해야 한다. 재현은 공개 데이터와 공개 코드로 수행하므로 추가 비용이 거의 없다.

### 3.2 Phase 1 — 선행 연구 재현 (1~2주차)

1. `stanfordnmbl/sit2stand-analysis` 저장소 clone, `requirements.txt` 설치
2. README의 링크에서 전처리 궤적(약 1.5GB)을 `videos/np/`로 다운로드
3. `GetMetrics.ipynb` 실행 → `results.csv` 생성
4. 제공된 `stats/dataClean.csv`와 대조. **검증 기준값: 405행, 5STS 시간 평균 11.40초**
5. **독립 Python 구현**으로 동일 궤적에서 동일 지표 산출

`dataClean.csv`의 실측 구성(직접 확인):

| 항목 | 값 |
|---|---|
| 규모 | 405명 × 738열 |
| 연령 | 평균 37.3세(18–96). 50세+ 106명, 65세+ 46명, 70세+ 27명 |
| 결과변수 | `OA_check`(양성 30), `GPH_TScore`, `GMH_TScore`, `fallsBin`, IPAQ |
| 운동학 | 무릎·고관절·발목·`trunk_lean`·`shank_angle` × range/max/min/각속도/각가속도 |
| 부재 | **사지근육량, 악력, 보행속도, 근감소증 진단 — 전무** |
| 단위 주의 | `Height` 인치, `Weight` 파운드 (BMI 역산으로 확인) |

5STS 12초 초과 비율: 전체 39%, 18–49세 32%, 50–64세 50%, 65세+ 65%.

**G1**: 시간 지표 절대오차 < 0.1초, 각도 지표 상관 r > 0.95. 미달 시 Phase 2로 진행하지 않는다.

### 3.3 Phase 2 — 동시 촬영 데이터 수집 (2~3주차)

**촬영 프로토콜** — `sit2stand.ai` 공식 지시문을 따른다. 선행 연구와의 비교 가능성을 위해 임의 변경하지 않는다.

- 카메라: 측면과 정면이 함께 보이는 **45°**, 거리 1.5–3m, 머리와 발이 프레임 내, 세로 방향, 밝은 실내
- 의자: 견고·독립형(벽에서 떨어뜨림)·바퀴 없음. 소파·리클라이너 금지
- 시작 자세: 편안히 착석, **양팔 가슴 앞 교차**, 양발 바닥에 평평히
- 수행: **5회, 가능한 한 빠르게.** 반복 사이 정지 없음, 완전 기립, 등받이 미접촉, 착석으로 종료
- 촬영자가 기립 횟수를 소리내어 센다

**자체 추가 절차**

- **계측 필수: 신장(cm), 체중(kg), 의자 좌면 높이(cm)** — Alcazar 식 입력. 선행 연구가 통제하지 못한 항목
- 헐렁한 하의 착용 금지 — 선행 연구에서 골반 추정 오류로 84개 영상이 제외된 원인
- **동기화**: 촬영 시작 시 박수 1회. 사후에 코 수직 궤적 교차상관으로 lag을 추정하고 박수 시점과 교차 확인
- 반복: 피험자당 3 trial, trial 간 2분 휴식(Baltasar-Fernandez 절차 준용)
- 악력계·체성분 분석기 접근이 가능하면 함께 측정하여 AWGS 근력 기준(남 <28kg, 여 <18kg)과 대조. 불가 시 명시

**장비**: Azure Kinect DK(Body Tracking SDK v1.1.2, 32 joint, 30fps) + 스마트폰(가능하면 60fps 고정). 하드웨어는 2023년 10월 단종되었으나 SDK·펌웨어는 2027년까지 유지된다.

**표본**: 목표 10명 × 3 trial = 30 trial. ICC 0.80을 95% 신뢰구간 하한 0.60 이상으로 보이기 위한 최소 수준이다. 선행 연구의 실험실 검증도 n=11이었다.

**G2**: 30 trial 확보. 미달 시 축소 분석 계획(피험자 수준 요약 중심, 신뢰구간 확대 명시) 발동.

### 3.4 Phase 3 — 측정 타당도 분석 (3~4주차)

**전처리** — 선행 연구와 동일하게 재현한다.

1. 결측 프레임 선형보간
2. **6Hz 5차 zero-lag Butterworth 저역통과** (`scipy.signal.butter` + `filtfilt`)
3. 신장 정규화 — 코–발목 거리의 95백분위수로 좌표 제산
4. 좌우 미러링 정렬

> `filtfilt`는 양방향 적용으로 실효 차수가 2배가 된다. 논문의 `fifth-order zero-lag` 해석은 Phase 1에서 논문 코드와 대조하여 확정한다.

**국면 분할** — 코 수직 위치의 국소최소(착석)와 국소최대(기립)로 STS·stand-to-sit 국면을 분리한다.

**산출 지표** (선행 연구 정의 준수)

| 계열 | 지표 |
|---|---|
| 시간 | 총 검사 시간, STS 국면 시간, stand-to-sit 국면 시간 |
| 각도 | 최대 체간 전방경사, 무릎각(발목–무릎–고관절), 고관절각(무릎–고관절–목), 발목각(제1중족골–발목–무릎) |
| 미분 | 각 관절의 각속도·각가속도 (이산차분 × fps) |
| 파생 | Alcazar 상대 STS 파워(W/kg), AWGS 5STS≥12초 이진값, 좌우 비대칭(\|좌−우\|÷평균) |

5주기 평균값을 사용한다.

**Alcazar 파워 산출**

```
힘 F        = 0.9 × 체중 × g              (정강이·발은 상승하지 않으므로 90%)
수직변위 d  = 0.5 × 신장 − 의자 좌면 높이
속도 v      = d / (1회 반복시간 중 신축 국면)
파워 P      = F × v
상대파워    = P / 체중                     (W/kg)
```

영상이 담당하는 입력은 **시간 하나**이며, 이는 2D 영상이 가장 정확하게 측정하는 지표다(r=0.997). 나머지 셋은 줄자·체중계로 실측한다. 계수와 신축 국면 비율은 Alcazar(2018) 원문으로 최종 확인한다.

**일치도 분석 — 네 지표를 함께 보고한다**

| 지표 | 답하는 질문 |
|---|---|
| ICC(2,1), 95% CI | 두 측정을 서로 바꿔 쓸 수 있는가 (절대적 일치) |
| Bland-Altman 편향 | 체계적으로 밀렸는가, 보정 가능한가 |
| Bland-Altman 95% LoA | 개별 측정이 최대 얼마나 벗어나는가 |
| RMSE, MAE | 원래 단위로 얼마나 틀렸는가 |

**Pearson 상관만으로 일치도를 판단하지 않는다.** 한쪽이 항상 5°씩 크게 읽으면 상관은 1.000이지만 실용적으로는 무의미하다. ICC 형태 선택과 보고는 Koo & Li(2016), Bland-Altman은 Bland & Altman(1986)을 따른다.

**G3 — 본 연구의 중심 게이트**: 지표별 신뢰도 등급(높음 ICC>0.90 / 보통 0.75–0.90 / 낮음 <0.75)을 확정한다. **Phase 4의 모델 입력과 Phase 5의 화면 표시는 이 등급을 따른다.** 두 단계를 연결하는 장치다.

### 3.5 Phase 4 — 증분가치 분석 (5주차)

**목표 재정의**: 근감소증 진단이 아니라 **저신체기능(AWGS 5STS≥12초) 및 신체건강 예측에서 동작 품질 지표가 갖는 추가 설명력**을 정량화한다.

공개 데이터에 근육량·악력·근감소증 진단이 없으므로 진단 모델은 원리적으로 불가능하다. AWGS 2019의 5STS≥12초는 국제 합의 기준에 근거한 **정당한 대리지표**이며, `근감소증 진단`이 아닌 `저신체기능 선별`로 표기한다.

**모델 구성** — 계단식 비교로 순환논리를 차단한다.

| 모델 | 입력 |
|---|---|
| M0 | Age, Sex, BMI |
| M1 | M0 + 5STS 시간 |
| M2 | M1 + G3 통과 동작 품질 지표 (체간 전방경사, 관절 각속도, 좌우 비대칭) |

**타깃**

- (a) `GPH_TScore` 회귀 — 405명 전원, 가장 안정적
- (b) `fallsBin` 분류 — 낙상 이력
- (c) `OA_check` 분류 — **양성 30/405(7.4%)**. ROC-AUC와 **PR-AUC 병기 필수**, 소표본 한계 명시
- (d) 50세 이상 하위군(n=106) 별도 분석

**검증 절차**

- **subject 수준 분할**(`StratifiedGroupKFold`) — 동일 피험자 데이터가 train/test에 갈라지면 누출
- 반복 5-fold CV로 분할 변동 확인
- **nested CV** — 하이퍼파라미터 탐색과 성능 추정 분리
- 알고리즘: XGBoost, RandomForest, Ridge/Logistic 비교
- 해석: SHAP

**보고 지표는 절대 성능이 아니라 ΔR² / ΔAUC다.** Chan et al.(2026)이 2,063건 영상 + 딥러닝으로 AUC 0.776을 얻었다. 405명 표본에서 그 이상을 주장하는 것은 근거가 없다. 개선분의 크기와 방향, 그리고 신뢰구간을 보고한다.

### 3.6 Phase 5 — 시스템 구현 (6주차)

Streamlit 기반 웹 인터페이스.

```
영상 업로드 → MediaPipe Pose(33 landmark) → 논문 동일 전처리
  → 국면 분할 → 지표 산출 → Alcazar 파워 → AWGS 임계값 대조
  → 시계열 시각화 + 예측 결과
```

**화면 필수 표시 항목**

1. 지표별 **Phase 3 신뢰도 등급** (높음/보통/낮음)
2. 추정값의 신뢰구간
3. **"선별 참고용이며 의학적 진단이 아님"** 고지
4. 촬영 품질 경고 — 45° 이탈, 프레임 이탈, 하의 문제로 골반 추정 실패 시

신뢰도 등급 노출은 감점 요소가 아니라 차별점이다. 검증되지 않은 수치를 단정적으로 제시하는 프로토타입과 구분된다.

**G5**: 자체 촬영 영상 1건이 업로드부터 결과 표시까지 통과.

### 3.7 사전 등록 기대치

**Phase 3 분석 착수 전에 확정하고 이후 수정하지 않는다.** 결과를 본 뒤 기준을 정하면 어떤 결과든 사후 합리화가 가능해지므로 분석의 의미가 소멸한다.

| 지표 | 기대 ICC | 근거 |
|---|---|---|
| 총 검사 시간 | **> 0.90** | Boswell 2023, 마커 기반 대비 r=0.997 |
| STS 국면 시간 | 0.80–0.95 | 국면 분할 오차 추가 |
| 무릎각 | 0.75–0.90 | Jo 2022 정면 스쿼트 무릎 ICC 0.90–0.91 |
| 체간각 | **0.50–0.80** | Boswell 2023 요추 굴곡 r=0.583, 측굴 r=0.702 |
| 고관절각 | **0.50–0.75 (최약)** | Jo 2022 가려진 고관절 ICC 0.64. 골반 추정 오류 |
| 각가속도 | 0.40–0.70 | 2회 미분에 의한 노이즈 증폭. Boswell 2023 r=0.556 |
| Alcazar 파워 | > 0.85 | 시간 지표에만 의존 |

체간각·고관절각이 낮게 나오는 것은 **선행 연구와 정합적인 결과**이며 실패가 아니다. 이를 사전에 명시하면 낮은 결과는 예측 확인, 높은 결과는 개선 입증이 된다.

## 4. 연구윤리 및 데이터 관리

**인체 대상 연구 절차**

동작 영상은 얼굴과 신체가 포함된 개인정보다. 가톨릭대학교 IRB 심의 대상 여부를 Phase 0에서 확인하고, 심의가 필요한 경우 승인 전 데이터 수집을 개시하지 않는다.

**7주 일정 내에 IRB 승인 후 고령자를 신규 모집하는 것은 불가능하다고 전제한다.** 따라서 피험자는 연구팀 및 서면 동의를 받은 성인 자원자로 한정하고, 고령층 검증은 후속 과제로 명시한다. 선행 연구의 실험실 검증 역시 n=11, 평균 27.7세였다.

**안전 기준** (선행 연구 포함 기준 준용)

- 최근 1주 내 의자에서 팔 지지 없이 기립 가능한 성인
- 신체활동 준비 질문지(PAR-Q) 위험 항목 전부 해당 없음
- 감독자 1인 동석. 통증·이상 시 즉시 중단

**데이터 관리**

- `data/raw/`는 읽기 전용. 정제는 코드로만 수행하고 수동 편집을 금지
- 얼굴 포함 원본 영상은 저장소에 커밋하지 않음(`.gitignore`)
- 식별정보와 계측값을 분리 보관, 피험자 ID로만 연결
- 공개 시 익명화 궤적(numpy)만 배포

## 5. 기대효과 및 활용방안

**직접 산출물**

1. **스마트폰 2D STS 지표의 신뢰도 등급표** — 어떤 지표를 어디까지 믿을 수 있는지에 대한 정량 근거. Azure Kinect와의 STS 비교 자료가 희박한 현 상황에서 자체적 가치를 가진다
2. **의자 높이를 통제한 프로토콜** — 선행 연구가 한계로 남긴 교란변수의 영향 확인
3. **MediaPipe 기반 파이프라인** — OpenPose와 달리 온디바이스 실행이 가능하므로 실사용 경로에 더 가깝다
4. **동작 품질 지표의 증분가치 정량화** — 초시계 대비 영상 분석의 추가 가치에 대한 근거

**활용 방향**

AWGS 5STS 임계값을 자동 판정하는 선별 도구는 검진 전 단계의 자가 확인, 원격 재활 경과 관찰, 지역사회 노인 대상 반복 모니터링에 적용 가능하다. 다만 본 연구 결과만으로 임상 적용을 주장하지 않으며, 고령층·근감소증 환자군에서의 검증을 선결 조건으로 명시한다.

## 6. 추진 일정

착수일 기준 상대 주차다. 실제 날짜에 고정해야 게이트가 작동한다.

| 기간 | 내용 | 게이트 |
|---|---|---|
| 착수 전 3일 | IRB 경로 확인, 동의서 작성, Kinect 작동 확인, 저장소 구축, 프로토콜 확정 | **G0** 스켈레톤 저장 성공 |
| 1~2주차 | 선행 연구 재현. 공개 궤적 처리, 독립 구현 대조 | **G1** 시간 오차<0.1s, 각도 r>0.95 |
| 2~3주차 | 동시 촬영. 10명×3trial, 신장·체중·의자높이 계측, 동기화 | **G2** 30 trial 확보 |
| 3~4주차 | 측정 타당도. ICC·Bland-Altman·RMSE/MAE, Alcazar 파워 | **G3** 신뢰도 등급 확정 |
| 5주차 | 증분가치 분석. M0/M1/M2, subject 수준 nested CV, SHAP | **G4** ΔR²/ΔAUC 산출 |
| 6주차 | Streamlit 구현. 신뢰도 등급·고지 포함 | **G5** end-to-end 통과 |
| 7주차 | 통합, 결과 분석, 한계 정리, 최종 보고서 | — |

**게이트 미통과 시 대응**

- G0 실패 → 스마트폰 단독 + 공개 데이터로 설계 축소. RQ1을 재현성 검증으로 대체
- G1 실패 → 코드 수정 후 재시도. 데이터 수집을 시작하지 않는다
- G2 미달 → 피험자 수준 요약 중심 축소 분석, 신뢰구간 확대를 한계로 명시
- G3에서 대부분 지표가 낮음 → 그 자체가 결과. RQ3을 시간 지표 중심으로 축소하고 "2D 영상의 가치는 시간 측정 자동화"로 결론

## 7. 연구의 한계

사후에 지적받기보다 사전에 명시한다.

1. **표본 연령 편중** — 7주 일정과 IRB 제약으로 피험자가 20대에 집중된다. 근감소증 주 대상인 고령층 검증이 불가능하다. 선행 연구의 실험실 검증(n=11, 27.7세)과 동일한 제약이다
2. **표본 규모** — 30 trial은 ICC 신뢰구간이 넓다. 점추정만으로 결론내지 않고 CI를 병기한다
3. **Azure Kinect의 오차** — Kinect는 정답이 아니며 자체 추정 오차를 갖는다. 특히 고관절과 가려진 분절이 취약하다. 관측된 불일치는 두 장비 오차의 합이며, 스마트폰만의 오차로 해석할 수 없다
4. **STS에 대한 Kinect 검증 자료 부족** — 인용 가능한 일치도 값이 스쿼트·런지 기반이다. STS 특이 참조값이 없어 기대치 설정의 근거가 간접적이다
5. **2D 투영 오차** — 45° 시야는 측면·정면 정보가 혼합된 값이며 순수 해부학적 평면 각도가 아니다
6. **자세추정 모델 차이** — MediaPipe(33 landmark)와 OpenPose(25 keypoint)는 골반 정의가 달라 선행 연구 수치와 직접 비교할 수 없다. 전처리 재현으로 방법 수준 비교만 가능하다
7. **근감소증 라벨 부재** — 대리지표(AWGS 5STS≥12초)를 사용하며 진단이 아니다. 근육량·악력 검증 없이 근감소증 유무를 주장하지 않는다
8. **공개 데이터의 불균형과 편중** — `OA_check` 양성 30/405(7.4%), 65세 이상 46명. 고령층·환자군 일반화 불가
9. **선별 도구의 한계** — 의료기기 인증이 없으며 진단·처방 목적으로 사용할 수 없다
