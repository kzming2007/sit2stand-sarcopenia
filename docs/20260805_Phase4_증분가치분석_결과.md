## 결론 요약

세 가지가 나왔고, **선형 모델과 RandomForest 양쪽에서 모두 재현됐다.**

| 발견 | Ridge / Logistic | RandomForest |
|---|---|---|
| **① 5STS 시간은 신체건강(GPH) 예측에 기여한다** | ΔR² **+0.0142** [+0.008, +0.020] 유의 | ΔR² **+0.0422** [+0.025, +0.060] 유의 |
| **② 비시간 운동학은 시간 위에 아무것도 더하지 못한다** | ΔR² −0.0127 / ΔAUC 전부 음 | ΔR² +0.0011 / 전부 불확실 |
| **③ 단, 비시간 운동학만으로 AWGS 임계값은 판별된다** | AUC 0.628 → **0.780**, Δ+0.153 [+0.137, +0.168] | AUC 0.608 → **0.831**, Δ**+0.223** [+0.196, +0.250] |

②의 표현에 주의가 필요하다. 선형 모델에서는 성능이 **떨어졌지만**(역방향) RandomForest에서는 **변화 없음**(불확실)이었다. 선형에서의 하락은 405명에 16개 특징을 넣은 과적합으로 설명된다. 따라서 정확한 진술은 **"운동학 지표는 기여하지 않는다"** 이며, "해롭다"가 아니다.

②와 ③이 모순처럼 보이지만 아니다. 운동학 지표는 **"느린 사람"을 식별하는 정보는 갖지만, 시간을 이미 아는 상태에서 건강 결과를 추가로 설명하지는 못한다.** 즉 시간의 **대체** 지표이지 **보완** 지표가 아니다.

계획서 §2에서 사전에 밝힌 대로, ②는 실패가 아니라 유효한 결과다. 결론은 **"2D 영상의 가치는 동작 품질 지표보다 시간 측정의 자동화·객관화에 있다"** 가 된다.

③은 RandomForest에서 더 강하게 나왔다(+0.223 vs +0.153). 운동학 지표와 임계값의 관계가 **비선형**일 가능성을 시사한다.

## 1. 분석 설계

### 모델 계단

핵심 구분은 **"초시계로 얻을 수 있는가"** 다.

| 모델 | 특징 | 수 |
|---|---|---|
| M0 | Age, Sex, BMI | 3 |
| M1 | + 5STS 총 시간 | 4 |
| M2 | + **비시간 운동학** (체간 경사·관절 각속도·수직 속도·좌우 비대칭) | 16 |
| M3 | + **시간 분해 지표** (국면 시간, 반복 간 변동) | 19 |

### M2 / M3 를 분리한 이유 — 누출 발견

당초 계획은 M2 하나로 묶는 것이었으나, 검증 중 문제를 발견했다.

```
corr( (time_sit2stand + time_stand2sit) × 5 , time ) = 0.9724
corr( time_stand2sit , time ) = +0.91
corr( time_sit2stand , time ) = +0.78
corr( time_sd        , time ) = +0.60
```

**국면 시간은 총 시간의 분해에 가깝다.** 이를 AWGS(= `time ≥ 12`) 판별에 쓰면 순환논리가 된다.

실제로 1차 실행에서 시간 분해 지표를 포함했을 때 AWGS 판별 AUC가 **0.964**로 나왔다. 이는 성능이 아니라 답을 입력에 넣은 결과다. 분리 후 정상적인 값(0.780)을 얻었다.

> 이 발견은 최종 보고서의 방법론 기여로 쓸 수 있다. "국면 분할 시간은 총 시간과 중복되므로 증분가치 분석에서 분리해야 한다."

### 검증 절차

- **5-fold × 10회 반복 = 50 fold.** 동일 fold에서 모든 특징 집합을 평가해 **쌍 비교(paired)** 가 가능하게 했다
- ΔR²/ΔAUC 는 fold별 차이의 평균과 95% CI(정규근사)
- 405명 = 405 subjectid 이므로 **1인 1행**이다. subject 수준 분할이 곧 일반 분할이며 그룹화가 불필요하다
- 결측 중위수 대치 → 표준화 → 추정기
- 주 모델: RidgeCV(회귀) / LogisticRegression(`class_weight='balanced'`)
- 소표본·소양성(30~34명)에서 하이퍼파라미터 탐색은 신뢰할 수 없으므로 선형 모델을 주로 쓰고 RandomForest를 보조로 비교했다

### 이 결과의 위치

2. Phase 3에서 운동학 지표의 측정 신뢰도를 검증할 가치가 있음을 뒷받침한다

## 9. 최종 보고서용 문구

> 선행 연구의 공개 데이터(405명)를 이용해 동작 품질 지표의 증분가치를 분석하였다. 인구통계(M0), 5STS 총 시간 추가(M1), 비시간 운동학 추가(M2)의 계단식 모델을 동일 교차검증 fold에서 쌍 비교하였다(5-fold × 10회 반복). 분석에 앞서 선행 연구가 보고한 다섯 개 상관계수를 모두 ±0.05 이내로 재현하여 특징 추출의 타당성을 확인하였다.
>
> 5STS 총 시간은 신체건강(PROMIS GPH) 예측에 유의하게 기여하였다(ΔR² = +0.014, 95% CI [+0.008, +0.020]). 그러나 비시간 운동학 지표를 추가한 경우 모든 결과변수에서 성능이 향상되지 않았다. 한편 총 시간을 배제하고 운동학 지표만으로 AWGS 저신체기능 기준(5STS ≥ 12초) 초과를 판별한 경우 ROC-AUC가 0.628에서 0.780으로 상승하였다(ΔAUC = +0.153, 95% CI [+0.137, +0.168]). 이는 운동학 지표가 신체기능 정보를 담고 있으나 총 시간과 정보가 중복되어 증분 기여가 나타나지 않음을 시사한다.
>
> 분석 과정에서 국면 분할 시간이 총 시간과 강하게 중복됨을 확인하였다(r = 0.972). 이를 분리하지 않으면 임계값 판별에서 순환논리가 발생하므로, 증분가치 분석에서는 시간 분해 지표와 비시간 운동학을 별도 블록으로 다루어야 한다.
>
> 골관절염을 결과변수로 한 분석은 연령 교란으로 해석이 제한되었다. 진단군의 평균 연령이 67.0세, 비진단군이 34.9세로 연령 단독 ROC-AUC가 0.918에 달해 추가 특징의 기여 여지가 없었다.
