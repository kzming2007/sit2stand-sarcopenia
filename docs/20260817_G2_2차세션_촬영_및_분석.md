## 결론

**피험자 2명 × 10 trial = 20 trial 을 확보했고 전량이 QC 를 통과했다.** 탈락 0건이다.

| 확인된 것 | 근거 |
|---|---|
| **시간 지표는 장비 간 사실상 동일하다** | 합본 ICC **0.996** [0.99, 1.00], 편향 −0.032초, LoA ±0.12초 |
| **파워도 그대로 따라온다** | P01 4.76 vs 4.75, P02 4.07 vs 4.05 W/kg |
| **각도는 폰이 일관되게 작게 읽는다** | 16개 비교 중 15개가 음의 편향 |
| **폰의 재현성은 Kinect 와 동등하다** | CV 대부분 1%p 이내 차이 |
| **각도 편향 크기가 피험자 간에 2~3배 다르다** | §4. 원인은 분리 불가 |

시간은 사전등록 기대치(0.90~1.00)를 적중했고, 각도는 기대치를 대부분 밑돌았다.
**계획서 §1의 전제 — "영상이 담당하는 입력은 시간 하나" — 를 지지하는 방향이다.**

### 시간이 답이다

`time` 은 **ICC 0.996, LoA ±0.12초**다. 30fps 기준 **프레임 3~4개** 폭이다.
사전등록 기대치 0.90~1.00 에 적중했고, Boswell 2023 이 보고한 마커 기반 대비 r=0.997 과
같은 수준이다. `alcazar_rel_power` 도 시간에서 파생되므로 그대로 따라온다(차이 0.01~0.02 W/kg).

### 각도는 편향의 성격이 지표마다 다르다

**편향과 산포는 다른 문제다.** 크기만 보면 오판한다.

| 지표 | 편향 | LoA 가 0 을 넘는가 | 성격 |
|---|---|---|---|
| `trunk_lean_range_mean` | −8.07° | **아니오** | **일정한 편향 → 보정 가능** |
| `right_knee_range_mean` | −1.04° | 예 | **편향은 없는데 산포가 최대. 보정 불가** |
| `left_hip_range_mean` | −16.12° | 예(간신히) | 편향도 크고 산포도 큼 |

`right_knee` 는 평균차가 1° 로 가장 좋아 보이지만 LoA 가 ±9° 다. 한 번 재서 쓰는
상황에서는 `trunk_lean_range`(편향 −8°, LoA 폭 ±5.3°)가 더 낫다. **평균차나 상관계수만
봤으면 정반대로 판단했을 것이다** — Bland-Altman 을 쓰는 이유가 이것이다.

`left_knee_range_mean` 과 `right_knee_range_mean` 에는 **비례편향**이 있다
(기울기 −1.013 p<0.001, −0.513 p=0.048). 값이 클수록 차이가 커지므로 상수 보정으로는
안 되고 회귀 보정이 필요하다.

## 4. 피험자 간 편향 차이 — 원인 분리 불가

| 지표 | P01 편향 | P02 편향 | 배율 |
|---|---|---|---|
| `trunk_lean_max` | −10.10° | −3.66° | 2.8× |
| `trunk_lean_range_mean` | −10.25° | −5.89° | 1.7× |
| `left_knee_range_mean` | −21.52° | −8.98° | 2.4× |
| `right_hip_range_mean` | −18.70° | −8.25° | 2.3× |
| `left_hip_range_mean` | −23.63° | −8.61° | 2.7× |
| `right_knee_range_mean` | −2.36° | +0.28° | — |
| **`time`** | **−0.01초** | **−0.06초** | 둘 다 무시 가능 |

**P01 의 각도 편향이 P02 의 2~3배다.** 방향은 같다(폰이 작게 읽음).

두 가지가 동시에 다르므로 **원인을 분리할 수 없다.**

| 후보 | 설명 |
|---|---|
| **줌 배율** | P01 1.0배 / P02 0.6배 |
| **체격** | P01 92kg / P02 63kg |

다만 **광학적으로는 줌이 설명이 되지 않는다.** 초점거리가 길수록(1배) 원근 왜곡이
**작아지므로**, 렌즈가 원인이라면 P01 이 더 좋아야 한다. 관측은 반대다.
따라서 **체격 쪽이 더 그럴듯하다** — 연부조직이 많으면 고관절·무릎 landmark 가
가려지거나 밀려 추정되고, 그것이 Kinect depth 기반 추정과 더 크게 갈린다.

**단정하지 않는다.** n=1 씩이고 두 요인이 완전 교락됐다. 최종 보고서에는
`체격 또는 렌즈에 따라 각도 편향이 2~3배 달라질 수 있다` 로 기술하고 한계로 남긴다.

> **해소 방법**: 한 사람이 0.6배·1.0배로 각각 3 trial 씩 찍으면 렌즈 효과만 분리된다.
> 30분이면 되고, 한계를 "모른다"에서 "이 정도다"로 바꾼다. **다음 촬영에서 우선 수행할 것.**

## 5. 재현성 — 폰이 Kinect 만큼 일관되다

같은 사람 10회의 변동계수(CV%). **사람이 적어도 성립하는 유효한 결과다.**

| 지표 | P01 폰 | P01 Kin | P02 폰 | P02 Kin |
|---|---|---|---|---|
| `trunk_lean_max` | **1.3** | 1.5 | 1.7 | 1.5 |
| `time` | 4.6 | 4.3 | 4.6 | 4.7 |
| `alcazar_rel_power` | 4.6 | 4.3 | 4.6 | 4.8 |
| `right_knee_range_mean` | 4.1 | 7.2 | 5.1 | 6.4 |
| `left_knee_range_mean` | **5.3** | **10.4** | 6.9 | 3.6 |
| `right_hip_range_mean` | 5.5 | 6.0 | 4.2 | 5.2 |
| `left_hip_range_mean` | 6.8 | 4.4 | 4.3 | 4.6 |
| `trunk_lean_range_mean` | 7.8 | 6.1 | 9.6 | 7.6 |

**폰이 Kinect 보다 나쁘지 않다.** 16개 대조 중 폰이 더 일관된 경우가 7개다.
P01 `left_knee` 는 폰 5.3% vs Kinect **10.4%** 로 폰이 두 배 안정적이다.

이는 중요한 함의를 갖는다 — **각도 지표의 장비 간 불일치는 폰이 불안정해서가 아니라
두 장비가 서로 다른 값에 안정적으로 수렴하기 때문이다.** 투영면 차이
(`kinect_playback.py` 주석 참조)와 landmark 정의 차이가 주된 원인일 가능성이 크다.

## 6. ICC 를 이 데이터로 해석하면 안 되는 이유

각도 지표의 ICC 가 대부분 `낮음` 으로 찍혔다. **"지표를 못 쓴다"로 읽으면 틀린다.**

ICC 의 분모는 **대상 간 분산**이다. 이번 표본은 두 사람의 **신장이 173cm 로 같고**
각도 범위도 비슷해서 분모가 거의 없다. 예컨대 `trunk_lean_max` 는 P01 204.7 / P02 211.2 로
6.5° 차이인데, 장비 간 편향이 6.9° 다. **대상 간 차이보다 측정 차이가 크니 ICC 가 무너진다.**

`time` 만 ICC 가 높은 이유도 같다 — P01 7.90초 / P02 9.23초로 대상 간 차이가 뚜렷하다.

`right_hip_range_mean` r=0.041, `left_hip_range_mean` r=−0.111 도 같은 현상이다.
두 사람의 참값이 겹쳐 있으면 상관이 나올 수 없다.

**따라서 이 데이터에서 ICC 는 판정 근거가 아니다.** `20260814` §6 의 전환안대로
**Bland-Altman 편향·LoA 와 재현성**을 주 결과로 삼는다. ICC 는 신뢰구간 폭과 함께
참고 표기만 한다. G3 는 `등급 확정` 이 아니라 **`오차 크기 기술`** 로 축소한다.

## 7. 표본 현황과 남은 한계

| 항목 | 현재 |
|---|---|
| 대상 수 | **2명** (`20260814` §5 기준 G3 달성률 5% 미만) |
| 관측 수 | 20 trial |
| 연령·체격 다양성 | 20대 2명, 신장 동일. **고령층 없음** |
| IRB | 회신 확인 전. 본 자료는 테스트 자료로 취급 |

**한계로 반드시 명시할 것**

1. 대상 수 부족으로 **ICC 등급 확정 불가.** G3 를 오차 크기 기술로 축소
2. 두 피험자의 **신장이 같아** 대상 간 분산이 구조적으로 작다
3. **줌 배율과 체격이 교락**되어 각도 편향 차이의 원인을 지목할 수 없다(§4)
4. 20대만이므로 **고령층 일반화 불가.** 원래 있던 한계다
5. 최종 보고서에 **`n=2 예비 타당도 연구`** 로 명시

## 8. 재현

```bash
# 피험자별 10 trial 일괄 (P01 예)
python scripts/mediapipe_pose.py  Test_Videos/Phone/P01_T01.mp4 --zero-lag --reps 5 \
       --height 173 --weight 92 --chair 44 \
       --save results/g2_phone_P01_T01.npy --json results/g2_phone_P01_T01.json
python scripts/kinect_playback.py Test_Videos/Kinect/P01_T01.mkv --reps 5 \
       --height 173 --weight 92 --chair 44
python scripts/pair_trials.py --phone results/g2_phone_P01_T01.npy \
       --kinect results/P01_T01_kinect.npy \
       --phone-json results/g2_phone_P01_T01.json \
       --kinect-json results/P01_T01_kinect.json \
       --subject P01 --id T01 --out results/g2_pairs_P01_all.csv

# 일치도
python scripts/phase3_agreement.py --pairs results/g2_pairs_P01_all.csv  --plot results/phase3_P01/
python scripts/phase3_agreement.py --pairs results/g2_pairs_P02_all.csv  --plot results/phase3_P02/
python scripts/phase3_agreement.py --pairs results/g2_pairs_both.csv     --plot results/phase3_both/
```

`pair_trials.py --out` 은 **append** 이므로 10 trial 을 한 CSV 에 쌓는다.

돌릴 수 없다. 계산 경로를 건드리는 수정은 데스크톱에서 한다.
