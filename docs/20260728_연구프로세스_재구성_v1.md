# Sit-to-Stand 근감소증 위험 평가 — 연구 프로세스 재구성 v1

작성일 2026-07-28 · 대상 문서 `2026_바이오헬스_경진대회_연구계획서.pdf`, `2026 바이오헬스 경진대회_신청서.pdf`

## 결론

연구의 1단계(하드웨어 교차 검증)와 3단계(시스템 구현)는 계획대로 실행 가능하다. **2단계(AI 예측 모델)는 현재 정의대로는 실행할 수 없다.** 선행 논문의 공개 데이터에 근감소증 라벨이 존재하지 않기 때문이다. 직접 내려받아 확인했다.

또한 계획서의 세 가지 표현이 심사에서 반박당할 위험이 있다. `Azure Kinect = Ground Truth`, `CoM 기반 STS Power`, `근감소증 위험도 예측`이다. 세 가지 모두 더 방어 가능한 형태로 바꿀 수 있고, 바꾸면 오히려 기여가 선명해진다.

아래는 순서를 재배치한 7주 프로세스다. 가장 중요한 변경은 **데이터 수집보다 논문 재현을 먼저 한다**는 것이다.

## 1. 구조적으로 수정해야 할 6가지

### P1. 근감소증 라벨이 없다 (치명적)

`stanfordnmbl/sit2stand-analysis`의 `stats/dataClean.csv`를 직접 내려받아 확인한 실제 구성이다.

| 항목 | 실측값 |
|---|---|
| 표본 | 405명 × 738열 |
| 연령 | 평균 37.3세, 범위 18–96세. **50세 이상 106명, 65세 이상 46명, 70세 이상 27명** |
| 성별 | 214 / 191 |
| 5STS 시간 | 평균 11.40초. 12초 이상 157명(39%) |
| 사용 가능한 결과변수 | `OA_check`(양성 30명), `GPH_TScore`, `GMH_TScore`, `fallsBin`, `BMI`, `Age`, `Sex`, IPAQ 신체활동 |
| 운동학 특징 | 무릎·고관절·발목·`trunk_lean`·`shank_angle` 각각 range/max/min/ang_vel/ang_acc — 이미 추출 완료 상태 |
| **없는 것** | **사지근육량(ASM), 악력, 보행속도, 근감소증 진단, DXA/BIA — 전무** |

`WOMAC_total` 열은 존재하지만 값이 전부 비어 있다. `orientation`은 405건 모두 0(좌우 정렬 완료), `framerate`는 24~120fps 혼재.

주의할 단위 함정: `Height`는 **인치**, `Weight`는 **파운드**다. (70 in / 168 lb → BMI 24.1로 검산됨)

**따라서 이 데이터로 근감소증 분류기를 학습시킬 수 없다.** 65세 이상이 46명뿐이라 고령층 일반화도 불가능하다.

**수정안 — 질문을 바꾼다.** 5STS 시간은 그 자체가 이미 AWGS 2019의 저신체기능 기준(≥12초)이고, 초시계만으로 측정된다. 그러므로 영상의 기여를 이렇게 정의해야 한다.

> 초시계로는 얻을 수 없는 **동작 품질 지표**(체간 전방경사, 각속도, 좌우 비대칭)가 시간 지표에 더해졌을 때 신체기능·건강 결과 예측이 개선되는가?

증분가치(incremental value) 질문이다. 실제로 존재하는 라벨만 쓰고, 순환논리가 없고, AWGS를 통해 근감소증과 임상적으로 연결된다. 모델 3개를 비교하는 구조가 그대로 나온다(§2 Phase 4).

### P2. Azure Kinect는 Ground Truth가 아니다

Azure Kinect는 마커 없는 깊이센서로, 그 자체가 마커 기반 시스템 대비 검증 대상이다. 보고된 값은 STS·스쿼트·균형 과제에서 ICC 0.83–0.95, 각도 오차 3–6°, 체간 기울기 ICC 0.88 / MAE 5°이며, **고관절이 가장 약하다**(측면 스쿼트 ICC 0.64–0.83, 정면 0.53–0.63).

심사위원 중 생체역학 전공자가 있으면 `Ground Truth` 표현은 바로 지적된다.

**수정안**: `기준 비교 장비(reference standard)`로 표기하고, 알려진 오차 범위를 먼저 밝힌다. 분석도 "정확도 평가"가 아니라 **방법 비교(method comparison)** 로 설계한다 — Bland–Altman 편향·95% 일치한계 + ICC(2,1)를 함께 보고. 선행 논문 자신도 체간각은 마커 기반 대비 r=0.58–0.70에 그쳤다. 이 사실을 먼저 인용해두면 여러분의 체간각 일치도가 낮게 나와도 예상된 결과가 된다.

### P3. 2D에서 CoM 기반 STS Power는 실패 위험이 높다

단일 45° 2D 뷰에서는 질량을 얻을 수 없고, CoM 수직 변위는 원근 왜곡을 받는다. 계획서의 `CoM 기반 생체역학 모델 → STS Power`는 구현 난도와 검증 부담이 모두 크다.

**수정안 — Alcazar(2018) 5STS 파워 식을 쓴다.** 필요 입력은 체중, 신장, **의자 좌면 높이**, 5STS 시간뿐이며 다리 길이 실측이 필요 없다. 선형변위계·Nottingham power rig·force plate 3종에 대해 60–93세 718명으로 검증되었고, 4개 후보식 중 노쇠·저악력 판별력이 가장 높았다.

핵심은 이것이다. **영상이 담당하는 부분은 `시간`이고, 시간은 2D 영상이 가장 잘 측정하는 지표다**(선행 논문 마커 기반 대비 r=0.997). 가장 약한 고리를 가장 강한 고리로 바꾸는 교체다.

구성 요소: 운동 관여 질량 = 0.9 × 체중, 수직 변위 = 0.5 × 신장 − 의자 높이, 속도 = 변위 ÷ (1회 반복시간의 신축 국면), 상대파워 = W ÷ 체중.
문헌 참조치(약 75세): 남 2.6±0.7 W/kg, 여 2.0±0.6 W/kg. 여러분의 산출값이 이 범위 밖이면 계산 오류 신호로 쓸 수 있다.

> 계수와 신축 국면 비율은 Alcazar et al. 2018 원문으로 최종 확인 필요. 본 문서 값은 2차 문헌(Baltasar-Fernandez 2021) 기준.

CoM 기반 파워는 **탐색적 보조 지표**로 남기고 별도 표기한다.

### P4. MediaPipe와 OpenPose는 호환되지 않는다

선행 논문은 OpenPose 25 keypoint를 썼다. 전처리도 명시되어 있다 — 결측 선형보간(영상당 <1%), **6Hz 5차 zero-lag Butterworth 저역통과**, 코–발목 거리 95백분위수로 신장 정규화, 좌우 미러링. 계획서의 MediaPipe는 33 landmark이고 골반 정의가 다르다. 논문 수치와 직접 비교가 불가능하다.

**수정안**: MediaPipe를 주 파이프라인으로 쓴다(설치 용이, 온디바이스 가능). 단 **전처리는 논문과 동일하게 재현**해 방법 수준의 비교 가능성을 확보한다. 그리고 §2 Phase 1에서 논문의 공개 궤적을 여러분 코드에 통과시켜 논문 수치가 재현되는지 먼저 확인한다.

### P5. IRB·연구윤리 게이트가 일정에 없다

사람의 동작 영상은 얼굴과 신체가 담긴 개인정보다. 7주 일정에 심의 절차가 빠져 있다.

**7주 안에 IRB 승인 후 고령자를 모집하는 것은 불가능하다고 보아야 한다.** 현실적 경로는 팀원 자체 촬영 + 서면 동의를 받은 소수 지인이다. 이 경우 연령대가 20대에 몰리므로, `고령층 검증은 후속 과제`로 정직하게 처리한다. 선행 논문의 실험실 검증도 n=11, 평균 27.7세였다 — 같은 수준이다.

### P6. 표본 수와 동기화

- **표본**: ICC 0.8을 95% 신뢰구간 하한 0.6 이상으로 보이려면 관측치 약 30이 필요하다. 목표를 **10명 × 3 trial = 30 trial**로 잡는다. ICC는 trial 수준, 요약은 피험자 수준으로 병기.
- **동기화**: Kinect 30fps와 스마트폰(30/60fps)은 별도 클럭이다. 촬영 시작 시 박수 1회로 기준점을 만들고, 사후에 코 수직 궤적 교차상관으로 lag을 추정해 박수 기준과 교차 확인한다.

## 2. 재구성한 프로세스

원 계획과의 가장 큰 차이는 **1~2주차에 데이터를 수집하지 않는다**는 점이다. 먼저 논문을 재현해 특징 추출 코드가 맞다는 것을 증명하고, 그 다음에 자체 데이터를 수집한다. 코드가 틀린 상태로 수집한 데이터는 전량 재분석 대상이 된다.

각 Phase 끝의 **게이트(G)** 를 통과하지 못하면 다음 Phase로 넘어가지 않는다.

### Phase 0 — 착수 전 3일: 게이트 해소

| 작업 | 산출물 |
|---|---|
| IRB 경로 및 피험자 범위 확정 | 동의서 양식, 심의 필요 여부 판단 근거 |
| Azure Kinect 실물 작동 확인 (Body Tracking SDK v1.1.2) | 32 joint 스켈레톤 저장 성공 로그 |
| 촬영 프로토콜 v1 확정 (§5) | 프로토콜 문서, 계측 기록지 |
| 저장소·디렉터리 생성, raw/processed 분리 규칙 | `README.md`, 데이터 관리 규칙 |

하드웨어는 2023년 10월 단종되었으나 SDK와 펌웨어는 2027년까지 유지되고 다운로드도 가능하다. 실물이 연구실에 있다면 문제없다.

**G0**: Kinect에서 스켈레톤이 실제로 저장되는가. 실패 시 전체 설계가 스마트폰 단독 + 공개 데이터로 축소된다 — 착수 전에 확인해야 하는 이유다.

### Phase 1 — 1~2주차: 논문 재현 (수집보다 먼저)

1. `stanfordnmbl/sit2stand-analysis` clone → `requirements.txt` 설치
2. README의 Google Drive 링크에서 전처리 궤적(약 1.5GB)을 `videos/np/`로 내려받기
3. `GetMetrics.ipynb` 실행 → `results.csv` 생성
4. 제공된 `dataClean.csv`와 대조: **5STS 시간 평균 11.40초, 405건**이 재현되는지 확인
5. **여러분의 독립 Python 구현**으로 같은 궤적에서 같은 지표 산출

**G1 — 통과 기준**: 독립 구현 대 논문 코드에서 시간 지표 절대오차 < 0.1초, 각도 지표 상관 r > 0.95.
미달 시 자체 데이터 수집으로 넘어가지 않는다. 비용이 거의 없고 확신을 가장 크게 올리는 단계다.

부수 효과: 논문 코드는 R(`sit2stand_clean-data_v15.Rmd`) + Jupyter 혼합이다. Phase 4 통계 분석을 여기에 얹을 수 있다.

### Phase 2 — 2~3주차: 동시 촬영

- 프로토콜은 `sit2stand.ai` 공식 지시문을 그대로 따른다(§5)
- Kinect(30fps, 32 joint) + 스마트폰(가능하면 60fps 고정, 세로) 동시
- 피험자당 3 trial, trial 간 2분 휴식
- **필수 계측: 신장(cm), 체중(kg), 의자 좌면 높이(cm)**

의자 높이는 중요하다. Alcazar 식의 입력이고, 동시에 **선행 논문이 통제하지 못해 한계로 남긴 항목**이다(참가자가 각자 의자를 골랐다). 여러분은 통제할 수 있다. 명확한 개선점이므로 반드시 기록한다.

- 악력계·체성분 분석기 접근이 가능하면 함께 측정한다. AWGS 근력 기준(남 <28kg, 여 <18kg)과 대조할 수 있으면 연구의 임상적 연결이 크게 강해진다. 불가능하면 그 사실을 명시한다.

**G2**: 30 trial 확보. 미달 시 축소 분석 계획(피험자 수준 요약 중심, ICC 신뢰구간 폭 확대 명시) 발동.

### Phase 3 — 3~4주차: 일치도 분석

지표별로 **ICC(2,1) + Bland–Altman(편향, 95% LoA) + RMSE/MAE**를 산출한다.

분석 전에 기대치를 문서에 고정한다(§4). 사전 등록해두면 낮은 값이 나와도 "예측대로"가 되고, 높은 값이 나오면 개선 근거가 된다. 결과를 보고 기준을 만들면 둘 다 잃는다.

Alcazar 파워는 영상 시간과 Kinect 시간으로 각각 계산해 두 값의 일치도를 보고, 절대값이 문헌 참조치 범위에 드는지 검산한다.

**G3 — 이 프로세스의 중심 게이트**: 어느 지표가 신뢰 가능한지 확정한다.
**Phase 4의 모델 입력은 G3를 통과한 지표만 쓴다.** 원 계획은 검증 단계와 모델 단계가 분리되어 연결이 약했다. 이 게이트가 두 단계를 잇는다.

### Phase 4 — 5주차: 공개 데이터 증분가치 분석

목표 재정의: `근감소증 진단` → **`저신체기능(AWGS 5STS ≥12초) 및 신체건강 예측에서 동작 품질 지표의 증분가치`**

모델 3개를 계단식으로 비교한다.

| 모델 | 입력 |
|---|---|
| M0 | Age, Sex, BMI |
| M1 | M0 + 5STS 시간 |
| M2 | M1 + G3 통과 운동학 지표 (`trunk_lean_max`, 각속도, 좌우 비대칭) |

타깃:
- (a) `GPH_TScore` 회귀 — 405명 전원, 가장 안정적
- (b) `fallsBin` 분류
- (c) `OA_check` 분류 — **양성 30/405(7.4%)**. ROC-AUC와 PR-AUC를 반드시 병기하고 소표본 한계를 명시
- (d) 50세 이상 하위군(n=106) 별도 분석

방법: subject 수준 5-fold CV 반복, nested CV로 하이퍼파라미터, XGBoost / RandomForest / Ridge·Logistic 비교. 보고는 **ΔR² 및 ΔAUC**와 SHAP.

핵심 결과는 "AUC 0.9 달성"이 아니라 **"동작 품질 지표가 시간 지표 대비 얼마를 더 설명하는가"** 다. 값이 작게 나와도 유효한 결과이며, 그 경우 결론은 "영상의 가치는 품질 지표보다 시간 측정의 자동화·객관화에 있다"가 된다. 이 역시 방어 가능한 결론이다.

### Phase 5 — 6주차: 시스템 구현

Streamlit: 영상 업로드 → MediaPipe → 논문 동일 전처리 → 지표 → Alcazar 파워 → AWGS 임계값 대조 → 시계열 그래프.

화면에 반드시 표시할 것:
- 지표별 **Phase 3 신뢰도 등급**(높음/보통/낮음)
- 신뢰구간
- `선별 참고용이며 진단이 아님` 고지

신뢰도 등급을 화면에 노출하는 것은 부담이 아니라 차별점이다. 대부분의 학부 프로토타입은 검증되지 않은 숫자를 단정적으로 보여준다.

**G5**: 자체 촬영 영상 1건이 업로드부터 결과까지 통과.

### Phase 6 — 7주차: 통합·보고

한계를 별도 절로 분리해 명시한다. 최소 항목: 표본 연령대 편중, 2D 투영 오차, Kinect 자체 오차, 근감소증 라벨 부재(대리지표 사용), 65세 이상 46명 한계, MediaPipe·OpenPose 차이.

## 3. 지표 정의

선행 논문 정의를 그대로 따른다. 자체 정의를 만들면 비교 대상을 잃는다.

| 지표 | 정의 |
|---|---|
| 총 검사 시간 | 첫 기립~마지막 기립(초) |
| STS 국면 시간 | 코 수직위치 국소최소(착석)~국소최대(기립) |
| Stand-to-sit 국면 시간 | 국소최대~국소최소 |
| 최대 체간각 | 고관절 수직벡터와 우측 고관절→목 벡터 사이 각(카메라 평면) |
| 체간 각가속도 | 각속도 이산미분 ÷ framerate |
| 무릎각 | 발목–무릎–고관절 |
| 고관절각 | 무릎–고관절–목 |
| 발목각 | 제1중족골–발목–무릎 |
| 각속도·각가속도 | 이산미분, framerate 정규화 |

전처리: 결측 선형보간 → 6Hz 5차 zero-lag Butterworth → 신장 정규화(코–발목 거리 95백분위수) → 좌우 미러링. 5주기 평균.

파생: Alcazar 상대 STS 파워(W/kg), AWGS 5STS ≥12초 이진값, 좌우 비대칭(|좌−우| ÷ 평균).

## 4. 사전 등록 기대치

**Phase 3 분석 착수 전에 확정하고 이후 수정하지 않는다.**

| 지표 | 기대 ICC | 근거 |
|---|---|---|
| 총 검사 시간 | **> 0.90** | 선행 논문 마커 기반 대비 r=0.997 |
| STS 국면 시간 | 0.80–0.95 | 국면 분할 오차 추가 |
| 무릎각 | 0.75–0.90 | Kinect 무릎 ICC 0.90–0.92(정면), 3–6° 오차 |
| 체간각 | **0.50–0.80** | 논문 r=0.58–0.70, Kinect 체간 MAE 5° |
| 고관절각 | **0.50–0.75 (최약)** | Kinect 고관절 ICC 0.53–0.83, 헐렁한 의복 시 골반 추정 오류 |
| 각가속도 | 0.40–0.70 | 이중 미분으로 노이즈 증폭 |
| Alcazar 파워 | > 0.85 | 시간 지표에만 의존 |

체간각·고관절각이 낮게 나오는 것은 실패가 아니라 **선행 연구와 일치하는 결과**다. 이를 미리 밝혀두는 것이 사후에 변명하는 것보다 강하다.

## 5. 촬영 프로토콜

`sit2stand.ai` 공식 지시문 기준.

**카메라** — 측면과 정면이 함께 보이는 45° 각도, 1.5~3m(5–10ft) 거리, 머리와 발이 모두 프레임 안에, 세로 방향, 밝은 실내.

**의자** — 견고하고, 벽에 붙이지 않은 독립형, 바퀴 없음, 소파·리클라이너 금지, 안정된 바닥. **좌면 높이 기록.**

**시작 자세** — 편안히 착석, **양팔을 가슴 앞에 교차**, 양발 바닥에 평평히.

**수행** — 5회, 가능한 한 빠르게. 반복 사이 정지 없음, 완전 기립, 등받이 접촉 금지, 착석으로 종료. 촬영자가 기립 횟수를 소리내어 센다.

**안전** — 통증·이상 시 즉시 중단. 팔 지지 없이 기립 가능한 사람만 참여. 감독자 1인 동석.

**추가(자체)** — 시작 시 박수 1회(동기화용). 신장·체중·의자 높이 계측. 헐렁한 하의 착용 금지 — 선행 논문에서 골반 추정 오류로 84개 영상이 제외된 원인이다.

## 7. 확인된 사실과 미확인 사항

**직접 검증함**
- `dataClean.csv` 405행 738열, 위 표의 모든 수치 — 파일 다운로드 후 실측
- 근감소증·악력·근육량 라벨 부재 — 열 이름 전수 확인
- `Height` 인치 / `Weight` 파운드 — BMI 역산으로 검증
- 5STS ≥12초 비율: 전체 39%, 65세 이상 65% (46명 중 30명)

**공개 원문에서 확인함** (아래 출처)
- 선행 논문 방법·지표 정의·전처리 파라미터·실험실 검증 n=11 및 상관값
- AWGS 2019 기준: 5STS ≥12초, 악력 남 <28kg / 여 <18kg
- Azure Kinect 대 마커 기반 일치도 범위
- Azure Kinect SDK 2027년까지 유지
- `sit2stand.ai` 촬영 지시문

**미확인 — 확인 필요**
- Alcazar 식의 정확한 신축 국면 비율과 계수 → 2018년 원문 필요
- 공개 궤적 Google Drive 링크의 현재 유효성 → Phase 1에서 즉시 확인
- 가톨릭대 IRB의 학부 경진대회 취급 방식

## 8. 팀 확인이 필요한 항목

프로세스 형태가 달라지는 항목만 남겼다.

1. **IRB 경로와 피험자 범위** — Phase 2를 막는 항목. 팀원 자체 촬영만인가, 동의서 기반 지인 포함인가. 고령자 모집은 7주 내 불가로 전제했다.
2. **7주 시작일** — 위 일정은 상대 주차다. 실제 날짜에 고정해야 게이트가 작동한다.
3. **악력계·체성분 분석기 접근 가능 여부** — 가능하면 AWGS 근력·근질량 기준과 직접 대조할 수 있어 연구 가치가 크게 오른다. Phase 2 프로토콜이 달라진다.
4. **Azure Kinect 실물 작동 상태** — Phase 0의 G0. 미작동 시 설계 전면 축소.
5. **P1 수정안(증분가치 질문으로 전환) 수용 여부** — Phase 4 전체와 신청서 문구가 여기에 달려 있다.
